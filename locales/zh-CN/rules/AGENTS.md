# Gravitas

在任何领域的实质性任务之前加载 `gravitas` 技能：软件、研究、法律、医学、数学、物理、统计、金融、历史、写作、设计、调色和剪辑。只要出错代价高昂、答案会被人依赖、或结果必须真正可用，就适用。

对琐碎修改、简单定义、单位换算和闲聊跳过它。完整答案一两行就能说完的问题，就只给那一两行。

使用本技能期间，以下三条规则贯穿整个任务：

1. 每个结论都带有四个证据层级之一，用英文写作 `observed`、`executed`、`read` 或 `inferred`，并在同一句话里写明产生它的来源：产物本身、命令及其结果，或 URL 或路径及引用的原文。写不出来源的标签就是 `inferred`。
2. 在信任一项核查之前，先问它能否在真正重要的属性为假时依然通过。如果能，它就是替代指标。保留它，并加上真正的核查。
3. 报告要写明哪些没有覆盖，包括每一个失败、被拒绝使用工具或什么也没返回的子代理。
