# 模块 03：分领域核查

## 用途

本模块讲两件事：在各个领域里，什么样的核查才算独立核查；以及哪个领域都躲不开的替代指标陷阱。结论不在软件范畴内，或者一时看不出该用什么核查来判定结论真伪时，加载本模块。

## 替代指标陷阱

真正要回答的问题不好查，旁边一个相关的问题却很好查，结果实际查的就成了好查的那个；它一通过，工作就被报成“已验证”。看着很严谨的工作最后出错，最常见的就是这种情况。只要验证在原理上做得到、实际操作又嫌麻烦，这个陷阱就会出现。

| 真正要问的问题 | 实际被查的替代指标 |
| :--- | :--- |
| 这个场景看上去像不像一座巧克力工厂？ | 是不是有 10 个托架、6 个滚筒？ |
| 这份合同真的产生了我说的那项义务吗？ | 文件里有没有 *indemnify*（赔偿）字样？ |
| 这个证明对不对？ | 每一行的写法是否规范？ |
| 这个物理计算结果对不对？ | 单位能不能约掉？ |
| 这项研究能不能支撑这个结论？ | 引用的论文是否真实存在？ |
| 这份译文是否忠实？ | 输出有没有语法错误？ |
| 这个财务模型靠不靠得住？ | 表格算下来有没有报错？ |
| 这段历史叙述准不准确？ | 有没有脚注？ |
| 用屏幕阅读器的人能不能正常使用这个页面？ | Lighthouse 无障碍评分是不是 100？ |
| 这个平台功能到底能不能用？ | 文档里有没有写到它？ |

右栏每一项核查都有必要，但没有一项是充分的：左栏的属性不成立，右栏照样可以通过。它们之所以诱人，正是因为查完能拿到一份满是绿色通过项的文档。

判断一项核查是不是替代指标，就看你真正关心的东西为假时，它能不能照样通过。能的话，这项核查保留，同时在旁边补上真正的核查。

一个实测案例：某次运行确认，3D 场景里恰好有一个巧克力网格，而且它的 UUID 在每个动画阶段都保持不变。可把渲染图交给一位独立的观看者，对方却报告画面里没有巧克力，因为这个网格从头到尾都没显示出来。两份报告都没错。网格数量顶替了“是否可见”，而整次运行里没有任何一项核查发现这次偷换。

## 各领域里的“观察”指什么

第 1 级是直接看对象本身，而“对象本身”是什么，因领域而异。不变的只有一点：它必须独立于得出该结论的那套推理。软件和渲染产物见 `04-runtime-verification.md`。

### 数学

把证明逐行读一遍，它对不对仍然只算 `inferred`，因为这样检查还是在推理。独立的核查是：在随机点上对命题做数值求值；测边界情况（零、一、空、负数、无穷）；检查极限和渐近行为；换一种独立的方法再验证一遍；动手构造反例。用工具跑过的核查算 `executed`，在脑子里推的仍是 `inferred`。一个闭式解只要在某一个点上和数值求值对不上，就是错的，推导写得再漂亮也没用。

### 物理与工程

先做量纲分析：它不花任何成本，又能抓出相当大一部分错误。接着拿一个已知量对比数量级，两者应当相差在 10 倍以内。再看极限情况：某个变量趋于零或无穷时，公式必须退化成已知结果。然后查守恒定律。能量无界增长、速度超过 `c`、长度比装置本身还长，这类问题不必信任推导，直接就能观察到。

### 法律

调出真正产生法律效力的那段原文，引用设定义务的那几句原话；不要引裁判要旨（headnote），也不要引任何概述。确认这项法律依据确实存在、现行有效，没有被推翻、废止或取代，并且在相关日期、相关法域内适用。把判决理由（holding）和附带意见（dicta）分开。引用能对上一个真实存在的案件，这只是替代指标；真正要查的是，它确实说了你声称它说的内容。

### 实证与事实类结论

要找到一手来源，而不是它的摘要。核对三点：来源里的数字就是被转述的那个数字；研究人群或适用范围与结论对得上；没有更新的资料取代它。一个经过三道二手来源转手的数字，最多算第 3 级，很多时候其实是套着引用外壳的第 4 级。

### 统计与数据

从原始数据重新算一遍。把总数对平。认定某个效应“很大”之前，先和基准率比一比；还要查分母，大多数误导人的百分比都出在分母上。

### 医学与应用型证据

核查三点：研究人群和眼前这个病例是否相似；效应量有没有临床意义，而不只是统计显著；这个发现是否被重复验证过。优先看系统综述，而不是单项试验；优先看试验本身，而不是介绍这项试验的新闻稿。剂量、药物相互作用和适用条件这类问题，答案取决于体重、肾功能、当前用药等输入；缺了这些输入，先给出不管它们取什么值都成立的内容，再把答案写成随它们变化的形式（比如按每公斤体重给剂量；取值不多时按每个取值分别作答，比如按体重分档），然后再问那个决定答案的输入。

### 金融与定量分析

换一条路径把算术重算一遍。确认各张报表之间勾稽一致。拿历史数据给增长率做一次合理性检查，因为一个看似合理的增长率复利 30 年，可能算出一个很离谱的数字：每年 7%、连续 30 年，是 7.61 倍，不是 3 倍。

### 翻译

独立做一次回译，再比较两个版本表达的意思。核对专业术语、单位、日期、名称和数字是否准确无误地保留下来。语法正确、读着通顺，只是替代指标；忠实于原文才是目标。

### 创作类工作：调色、剪辑、写作、设计

这类工作没有唯一正确答案，所以迭代循环的规则也不一样，替代指标陷阱也换了个样子。每一门创作都分可核查层和可评判层，两者一混，作品交出去时就会看着不对劲。

可核查层是实打实的，而且常常能客观地判定违规与否：电平和色域是否符合广播规范，高光有没有溢出、暗部有没有死黑，色彩空间和传递函数标签，整段时长内（而不只是开头）的音画同步，帧率是否符合目标规格，画幅比例，叙事里各类名称和事实前后是否一致，字数是否符合规格要求。这些属于第 1 级和第 2 级，要实际去测。

可评判层看的是：作品能不能让人看明白、能不能打动人、像不像它自称的那个东西。任何指标都够不着这一层。一版调色可以完全落在合规范围内，看上去却又闷又脏。一段剪辑可以每一刀都踩在节拍上，却毫无节奏感。一段文字可以字数刚好达标，句句用主动语态、干净利落，一个副词也没有，却言之无物。

可核查层是必要的，也正因为必要，过了这一层就让人觉得已经验证完了。可评判层要请一位全新的评审者看两遍。第一遍不给 brief（需求说明）：这看起来像什么，讲的是什么，透出什么情绪。第二遍附上 brief：它有没有实现意图，差在哪里。只做第二遍，等于引着评审者去附和刚递到它手里的意图。

审美判断属于 `inferred`。要标明层级，但判断照样要给，因为不肯下判断本身就是一种失败。

### 网页设计与界面

这个领域的可核查层格外丰富：对比度、点击目标大小、标题层级顺序、有没有替代文本（alt text）、键盘焦点是否可见、各个断点下的布局、有没有横向滚动。自动化审计会把这些逐项报出来并打一个分，这个分数就是替代指标。2017 年的一次政府测试中，13 款自动化工具在 142 个故意设置的障碍里，找出的比例在 13% 到 40% 之间（read: https://alphagov.github.io/accessibility-tool-audit/）；一家工具厂商对 2000 多次审计做的研究显示，按问题数量算，自动化测试发现了 57%（read: https://www.deque.com/blog/automated-testing-study-identifies-57-percent-of-digital-accessibility-issues/）。剩下的要靠判断：标题能不能概括它下面那一节，链接文字脱离上下文还有没有意义，阅读顺序和视觉顺序是否一致，错误提示有没有告诉用户该怎么办。有没有替代文本可以测量，替代文本有没有用则测不出来。

页面在 Lighthouse 上拿满 100 分，照样可能没法用。找一位只拿到页面、不附任何说明的观看者来核查：第一次来的访客能不能找到主要操作，信息层级是否清楚，界面看起来是否可信。

### 历史与解读

去看文献本身，而不是别人对它的叙述。确定出处和日期，并留意这份叙述流传下来，谁从中得了好处。这个领域很多内容都停留在第 3 级，诚实的报告会写明这一点。

## 遇到新领域时怎么划分两层

上面列的领域并不全。建筑、烹饪、音乐制作、教学、摄影、用户体验研究，都可以用同样三个问题拆开。

1. 这里有哪些东西能用机器测量？这就是可核查层，对应第 1、2 级。去测，因为成本低，而且必不可少。
2. 哪些东西只能由懂行的评判者来下结论？这就是可评判层，这一层的结论都是 `inferred`。这一层需要评审者，结论要始终标明是判断。
3. 哪个指标会让人觉得“已经验证过了”？动手之前就把它点出来。它几乎总是真实、必要、报出来很有成就感的东西，陷阱恰恰就在这里。

如果第三个问题找不到答案，说明这个领域的验证很容易，替代指标陷阱不适用。

宣布某件事没法核查之前，先想想一个低成本的检验手段会是什么样：一次数值求值、一次调取法条原文、一次数量级对比、一次一手来源检索。这些只要几分钟，就能了结那些 agent 原本要争论半天、最后还得出错误结论的问题。数值求值不管推导有多优雅，法条原文也不管你记得它是怎么写的；正因为如此，同一条原则从代码到法律再到物理，都原样适用。
