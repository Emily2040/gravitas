# 模块 03 - 领域核查

## 用途

本模块说明在各个领域中什么才算独立核查，以及在每个领域都会出现的替代指标陷阱。当一个结论不属于软件领域，或能够判定该结论的核查方式并不明显时，加载本模块。

## 替代指标陷阱

当真正的问题难以核查、而相邻的问题容易核查时，被核查的往往是容易的那个；它通过了，工作随即被报告为“已验证”。这是看似严谨的工作最常见的出错方式，只要验证在原则上可行、在实践中麻烦，它就会发生。

| 真正重要的问题 | 实际被核查的替代指标 |
| :--- | :--- |
| 这个场景看起来像一座巧克力工厂吗？ | 是否有 10 个托架和 6 个滚筒？ |
| 这份合同是否产生了我所说的义务？ | 文件里是否出现了 *indemnify*（赔偿）一词？ |
| 这个证明正确吗？ | 每一行的格式都规范吗？ |
| 这个物理答案对吗？ | 单位能否约掉？ |
| 这项研究支持该结论吗？ | 被引用的论文是否存在？ |
| 这份译文忠实吗？ | 输出是否合乎语法？ |
| 这个财务模型稳妥吗？ | 表格计算时是否不报错？ |
| 这段历史叙述准确吗？ | 有没有脚注？ |
| 使用屏幕阅读器的人能用这个页面吗？ | Lighthouse 的无障碍评分是否为 100？ |
| 这个平台功能能用吗？ | 文档里是否描述了它？ |

右栏的每一项核查都是必要的，但没有一项是充分的：每一项都可能在左栏属性不成立时照样通过。正因如此它们才诱人，因为它们能产出一份满是绿色结果的文档。

判断一项核查是否为替代指标，就看它能否在你真正关心的事情为假时依然通过。如果能，就保留它，并在旁边加上真正的核查。

一个实测案例：一次运行确认某个 3D 场景中恰好有一个巧克力网格，其 UUID 在所有动画阶段都保持不变。一名拿到渲染图的独立观察者却报告巧克力不存在，因为这个网格从未可见。两份报告都没错。网格数量替代了可见性，而这次运行中没有任何核查发现这种替换。

## 各领域中“观察”的含义

第 1 层是直接查看事物本身，而“事物本身”是什么随领域而变。不变的是：它必须独立于产生该结论的推理。软件与渲染产物见 `04-runtime-verification.md`。

### 数学

逐行阅读一个证明属于第 3 层。第 1 层是：在随机点上对命题做数值求值，测试边界情况（零、一、空、负、无穷），检查极限与渐近行为，用第二种独立方法验证，并尝试构造反例。一个闭式解只要在某一点上与数值求值不符，就已失效，无论推导读起来多么干净。

### 物理与工程

先做量纲分析，因为它不花成本，并能抓住相当大一部分错误。然后与已知量比较数量级，预期误差在 10 倍以内。然后检查极限情况：当某个变量趋于零或无穷时，公式必须退化为已知结果。然后检查守恒定律。无界增长的能量、超过 `c` 的速度、比装置还长的长度，都无需信任推导即可观察到。

### 法律

调出实际生效的条文，引用产生义务的原话，而不是判决摘要或概述。确认该法律依据确实存在、仍然有效、未被推翻、废止或取代，并且在相关日期适用于相关法域。区分判决理由（holding）与附带意见（dicta）。一个能指向真实案件的引用，只是“引用内容确如所述”的替代指标。

### 实证与事实性结论

直接找到一手来源，而不是它的摘要。核对来源中的数字就是被转述的数字，人群或范围与结论相符，且没有更新的来源取代它。一个经过三道二手来源转述的数字，最好也只算第 3 层，而且常常是披着引用外衣的第 4 层。

### 统计与数据

从原始数据重新计算。核对总数。在接受“效应很大”之前先与基准率比较，并检查分母，大多数误导性的百分比都出在分母上。

### 医学与应用证据

核查研究人群是否与眼前的情况相似，效应量在临床上是否有意义而不仅仅是统计显著，以及该发现是否被重复验证过。系统综述优于单项试验，单项试验优于关于该试验的新闻稿。剂量、相互作用和适用资格的答案取决于体重、肾功能、当前用药等输入；这些输入缺失时，答案要么以它们为变量给出，要么不给。

### 金融与定量工作

用第二条路径重新计算。确认各报表相互勾稽。将增长率与历史对照做合理性检查，因为一个把看似合理的增长率复利 30 年的模型，可能得出不合理的数字：每年 7%、持续 30 年是 7.61 倍，而不是 3 倍。

### 翻译

独立进行回译，并比较两个版本各自的含义。核对专业术语、单位、日期、人名和数字是否被原样保留。合乎语法、行文流畅的输出是替代指标；忠实的输出才是目标。

### 手艺类工作：调色、剪辑、写作、设计

这些工作没有唯一正确答案，因此循环规则不同，替代指标陷阱也换了形状。每门手艺都有可核查层与可评判层，混淆两者就是作品带着明显问题交付的原因。

可核查层是真实存在的，而且常常可以被客观地违反：广播合规的电平与色域、高光溢出或暗部死黑、色彩空间与传输函数标签、整段时长（而不只是开头）的音画同步、帧率一致、画幅比例、叙事中人名与事实的连贯、对照规格的字数。这些属于第 1 层和第 2 层。去测量它们。

可评判层是：作品是否读得通，是否打动人，看起来是否像它声称的那样东西。没有任何指标能触及这一层。一个调色可以处于合规范围内却显得浑浊。一段剪辑可以踩中每一个节拍却毫无节奏。一段文字可以用干净的主动语态、零副词达到字数要求，却什么也没说。

可核查层是必要的，这使得通过它感觉像是验证。对可评判层，请一位新的评审者看两次。第一次不给简报：它读起来像什么，讲的是什么，带着什么情绪。第二次附上简报：它是否实现了意图，具体差在哪里。只做第二次，会诱使评审者去确认刚刚交给它的意图。

品味判断最多属于第 3 层，通常属于第 4 层。给它们标上层级，但仍然要给出判断，因为拒绝评判本身也是一种失败。

### 网页设计与界面

这里的可核查层异常丰富：对比度、点击目标尺寸、标题层级、是否有替代文本、键盘焦点是否可见、各断点下的布局、有无横向滚动。自动化审计会报告这些并给出一个分数，而这个分数就是替代指标。在 2017 年的一次政府测试中，13 款自动化工具在 142 个刻意设置的障碍中只发现了 13% 到 40%（read: https://alphagov.github.io/accessibility-tool-audit/），一家工具厂商对 2,000 多次审计的研究按问题数量统计为 57%（read: https://www.deque.com/blog/automated-testing-study-identifies-57-percent-of-digital-accessibility-issues/）。其余需要判断：标题是否描述了其下的内容，链接文字脱离上下文是否有意义，阅读顺序是否与视觉顺序一致，错误提示是否告诉用户该怎么做。有替代文本可以测量，替代文本有没有用则不能。

一个页面可以在 Lighthouse 上得 100 分，却仍然无法使用。请一位只拿到页面、没有任何解释的观看者来核查：初次访问的人能否找到主要操作，层级是否读得通，界面看起来是否可信。

### 历史与诠释

去看文献本身，而不是关于它的叙述。确定出处和日期，并留意谁从这份叙述的流传中获益。这个领域的大部分内容处于第 3 层，诚实的报告会如实说明。

## 为新领域推导两层划分

上面的列表并不完整。建筑、烹饪、音乐制作、教学、摄影和用户体验研究，都可以用同样三个问题来划分。

1. 这里有什么是机器可以测量的？这就是可核查层，第 1 和第 2 层。去测量，因为它便宜且必要。
2. 有什么只有称职的评判者才能决定？这就是可评判层，第 3 和第 4 层。它需要评审者，结论要始终标注为判断。
3. 哪个指标会让人感觉像是验证？在开始前就说出它的名字。它几乎总是真实、必要、报告起来令人满足的东西，正因如此才是陷阱。

如果第三个问题没有答案，说明这个领域的验证很容易，替代指标陷阱不适用。

在宣布某件事无法核查之前，先想一想一个廉价的检验装置会是什么样：一次数值求值、一次调取法条、一次数量级比较、一次查找一手来源。这些只需几分钟，却能解决那些代理们原本会长时间争论、最终还争错的问题。数值求值不在乎推导有多优雅，法条原文不在乎你记得它怎么说，这就是同一条原则能从代码原样延伸到法律和物理的原因。
