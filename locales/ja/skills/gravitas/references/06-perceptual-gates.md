# モジュール 06 - 知覚ゲート

## 目的

このモジュールは、見る人にしか答えられない検証を扱います。対象は人が目にするものすべて、つまりシーン、ページ、グラフ、生成画像、組版された文書です。作業に視覚的な結果があるときは `05-acceptance.md` と一緒に読み込みます。もとになった事例は、そこで説明しているチョコレート工場です。

## スクリーンショットは検証ではない

チョコレート工場の実行は、報告に 8 枚の PNG を添付しました。それらが裏づけたゲートはすべて幾何を測っていました。UUID の保持、メッシュ数、`Y = 1.084 m` でのグリッパーの隙間、0.1 mm 未満のサイクル境界誤差です。どれも正しく、それでもシーンはおかしく見えました。画像が正しく見えるかを問うものは何もありませんでした。スクリーンショットは判断すべき画像としてではなく、スクリプトが走った証拠として綴じられていました。

この失敗が魅力的なのは、数字と合格で埋まった文書ができあがり、見るよりも厳密に感じられるからです。しかし答えているのは別の問いです。

| | 幾何的な検証 | 知覚的な検証 |
| :--- | :--- | :--- |
| 問い | 要素が存在し、位置と大きさが正しいか | 正しく見えるか |
| 方法 | シーングラフや DOM へのスクリプトのアサーション | モデルが画像を見て判断する |
| 捕まえるもの | ノードの欠落、誤った変換、数のずれ | 平板な照明、プラスチックのような質感、読み取れない形 |
| 捕まえられないもの | 見た目に関することすべて | 正確な値に関することすべて |

知覚的な検証はスクリプトにできません。新しい批評役の前に画像を置き、どう見えるかについての問いを投げる必要があります。

## 知覚ゲート

人が目にするものには、見る人にしか答えられないゲートを加えます。`gravitas-visual-critic` に取得画像と意図を渡し、具体的な答えを求めます。

「良く見えますか」は同意を誘うだけです。次の問いは、間違い得る答えを引き出します。

- 主要な各表面が何の素材に見えるかを挙げてください。趣意書には銅、ほうろう鋼、真鍮とあります。何が見えますか。
- チョコレートを指し示してください。この画像で見つけられなければ、そう言ってください。
- 光の向きは見て取れますか。それを挙げてください。照明が平板に見えるなら、平板と言ってください。
- テクスチャ、摩耗、変化のない表面をすべて挙げてください。
- 趣意書を読んだことのない人は、これをチョコレート工場だと認識するでしょうか。代わりに何が見えますか。

批評役は見る人として答え、ソースは読みません。コードを読んだ批評役は、画像ではなく意図を説明するからです。最も役に立つ問いはひとつ、「これは何でできているように見えるか」です。フラットシェーディングのプリミティブで組んだシーンは、素材設定が何を主張していても「プラスチックのブロック」と答えられます。

## 作る前に目標を名指す

その実行の計画は具体的でした。粗さ 0.20、クリアコート 0.85 の `#941c33` ラズベリー色のほうろう、強度 2.8 の 3500 K ハロゲンのキーライト、プロシージャルなタイル目地。これらは本物の受け入れ基準であり、どれひとつゲートになりませんでした。計画は見た目を記述し、テストスイートは位置を測りました。

計画に書かれた素材と照明の仕様は、どれも書かれるのを待っている知覚ゲートです。計画にクリアコート 0.85 とあれば、ゲートは表面が塗装されたように見えるかを問います。ある位置の 3500 K のキーライトを指定していれば、ゲートは見る人が光の向きと暖かさを言い当てられるかを問います。

## コンソール出力もゲートである

同じシーンは、r186 で削除された `THREE.PCFSoftShadowMap` を要求していました。レンダラーはハードシャドウにフォールバックし、そのことをコンソールに出していました。

```text
THREE.WebGLShadowMap: PCFSoftShadowMap has been removed. Using PCFShadowMap instead.
```

何も失敗せず、何もクラッシュしませんでした。影は計画の求めたものではなく、その実行はコンソールの取得を配線しておきながら読んでいませんでした。非推奨の警告は手に入る中で最も安い欠陥のシグナルです。コードが呼んでいる API を名指しする警告は、誰かが仕分けるまで失敗として扱います。

## 赤くなる実例

`examples/gates.example.js` は、これらの規則に沿って書かれ、上のシーンに対して実行された Playwright のゲートスイートです。6 項目中 4 項目を満たし、終了コード 1 で終わります。

```text
PASS  G1  Zero console errors
FAIL  G2  No deprecation warning for an API this code calls
          THREE.WebGLShadowMap: PCFSoftShadowMap has been removed. Using PCFShadowMap instead.
FAIL  G3  Shadow map enabled and not the hard fallback (type !== 1)
          enabled=true type=1
PASS  G4  Under 90% of materials are untextured
          153/193 materials have no map (79.3%)
PASS  G5  Component counts match the brief
PASS  G6  SELF-TEST: an injected wrong value is detected by G5 logic
```

G6 は規則が求める自己テストです。誤った値を注入し、比較がそれを捕まえることを確かめるので、このスイートは赤くなれることを示しています。元のスイートでは、同じシーンが `ALL TEST GATES PASSED SUCCESSFULLY` と報告していました。

そのあと知覚ゲートを別に実行しました。スクリーンショットだけを渡され、ソースは渡されていない新しいエージェントによるものです（以下は原文の引用）。

> **Chocolate: Absent.** The mold cavities are completely white and empty; there is no liquid chocolate, bar, or brown confectionery substance visible anywhere on the line.
>
> **Lighting: Flat.** No directional cast shadows, no specular hot spots.
>
> **What it looks like it is made of:** injection-molded matte toy plastic and raw CAD primitives.

元のスイートの同じ対象へのゲートはこうでした。「Hero Chocolate Identity Persistence - PASS. Exactly 1 mesh throughout; UUID persists across all phases.」 メッシュはシーングラフに存在し、レンダリングには見えていません。幾何的なゲートではこの隔たりを埋められず、だからこそ知覚ゲートが存在します。
