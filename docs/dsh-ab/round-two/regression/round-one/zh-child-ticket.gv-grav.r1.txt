**这张票省不了：你女儿7岁，必须买儿童优惠票。**

你说的“1.2米以下免票”是2023年以前的老规定。2023年1月1日起，铁路儿童票改为**按年龄**算，按乘车日期计算年龄：

| 年龄 | 票 |
|---|---|
| 未满6周岁、不单独占座 | 可由一名持票成人免费带一名，需提前在12306申报，**没有座位** |
| 年满6周岁、未满14周岁 | **必须买儿童优惠票**，有座位 |
| 14周岁以上 | 全价票 |

你女儿已经满6周岁，所以1.15米这个身高在新规里不起作用。只买两张票让她挤一挤，等于她无票乘车：春运车厢满员，查票时会被要求补票，补到的多半也不是连座；北京西到长沙南要坐5个半小时到6个半小时，7岁孩子全程没座也不现实。

**改成：2张成人票＋1张儿童优惠票，买同一排三个连座（二等座A、B、C那一侧）。** 儿童优惠票二等座按全价执行票价的50%算，通常接近成人票的一半；三口人比只买两张多花的，就是这半张票的钱。

买票时注意：

- 用女儿本人的有效身份证件买，不能挂大人的证件。在12306添加乘车人时，优惠类型选“儿童”。
- 没有身份证：12306线上不支持户口簿，带户口簿去车站窗口买；或者出发前办好身份证。
- 儿童票要和大人同车次、同日期、同席别，到站不能比大人远；最好同一订单买，方便选连座。
- 儿童优惠票退改签规则和成人票一样。
- 7岁不适用“免费乘车儿童申报”，那是给未满6周岁、不占座的孩子。

## 出发前清单

### 一、票和证件
- [ ] 2张成人票＋1张儿童优惠票，同车次、同日期、同席别、同到站
- [ ] 选座选三人连座（二等座A、B、C）
- [ ] 女儿身份证；没有就带户口簿去窗口买或取，或提前办好身份证
- [ ] 你和老公的身份证
- [ ] 12306订单截图存手机
- [ ] 返程票一起买好（春节后返程更紧张）

### 二、抢票和行程
- [ ] 查好北京西→长沙南的车次，记下起售时间，设闹钟
- [ ] 开售就买；买不到就挂候补，同时候补几个车次和席别
- [ ] 关注春运加开列车
- [ ] 确认票面出发站（多为北京西）和到站（长沙南），别跑错站
- [ ] 出发当天提前60～90分钟到站，春运安检排队
- [ ] 长沙南下车后怎么走提前查好，春运打车难，可提前约车

### 三、孩子随身小包（让她自己背）
- [ ] 保温杯，装温水，别装刚烧开的水
- [ ] 小零食：面包、饼干、水果、独立包装的小零食
- [ ] 小包纸巾、湿巾
- [ ] 贴纸书、画笔、小本子、一个小玩具
- [ ] 薄外套或小毯子（车厢空调）
- [ ] 备用内衣裤、袜子一套

### 四、大人包里
- [ ] 保温杯、瓶装水
- [ ] 面包、饭团、水果，孩子饿了能马上吃
- [ ] 湿巾、纸巾、垃圾袋
- [ ] 充电宝（不超过100Wh、标识清晰）＋充电线
- [ ] 平板或手机提前下好动画片，儿童耳机
- [ ] 雨伞（长沙冬天可能下雨）
- [ ] 行李尽量少：一个箱子＋一个背包，春运人多

### 五、药品
- [ ] 儿童退烧药（布洛芬或对乙酰氨基酚，按体重算好剂量）、电子体温计
- [ ] 感冒药、肠胃药、创可贴、碘伏棉签
- [ ] 晕车药或晕车贴（如果她晕车）
- [ ] 她平时用的药、过敏药
- [ ] 医保卡或医保电子凭证
- [ ] 口罩几个

### 六、穿的（北京冷、长沙湿冷、车厢暖）
- [ ] 三层穿：速干内衣＋毛衣或抓绒＋羽绒服，方便穿脱
- [ ] 帽子、围巾、手套
- [ ] 防滑保暖的鞋（站台可能湿滑）
- [ ] 老家没暖气的话，带厚睡衣或睡袋

### 七、安全
- [ ] 女儿口袋放一张写有父母电话的卡片
- [ ] 教她走散后找穿制服的工作人员或服务台，约定一个集合点
- [ ] 上下车牵手，站台站在黄线内，注意车门缝隙
- [ ] 不让她自己接开水（开水炉很烫）、不单独去洗手间
- [ ] 行李做标记，贵重物品随身
- [ ] 进站时女儿没身份证就走人工通道

### 八、别带
- [ ] 自热火锅、自热米饭（部分列车禁用，蒸汽也容易烫伤）
- [ ] 超过100Wh的充电宝、大瓶酒精喷雾
- [ ] 味道大的食物（车厢封闭，影响别人）

出发当天上车前先带她上一次厕所；车上少吃甜食和碳酸饮料，防晕车。
