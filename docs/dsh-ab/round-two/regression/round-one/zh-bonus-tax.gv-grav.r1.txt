先纠正一个会直接影响你拿钱的前提：**同事说错了，单独计税的优惠没有取消。**

《财政部 税务总局关于延续实施全年一次性奖金个人所得税政策的公告》（财政部 税务总局公告2023年第30号）把这项政策延续到了**2027年12月31日**，而且政策原文写的是“可以不并入当年综合所得……单独计算纳税”，第二条又写“也可以选择并入当年综合所得”。也就是说，**单独计税和并入计税是二选一，不是强制并入**。你年终奖下个月发，只要发放年度在2027年底之前，就仍然可以选单独计税。（[国家税务总局天津市税务局转载原文](https://tianjin.chinatax.gov.cn/11200000000/0300/030004/03000418/20230829143229845.shtml)）

## 按你给的数，两种算法对比

综合所得年度税率表：14.4万–30万这一档税率20%，速算扣除数16,920。

**如果并入综合所得：**

| | 应纳税所得额 | 税额 |
|---|---|---|
| 不含年终奖 | 180,000 | 180,000×20%−16,920 = **19,080** |
| 并入36,000后 | 216,000 | 216,000×20%−16,920 = **26,280** |
| 差额 | | **7,200** |

这36,000的税负就是**7,200元**，正好是36,000×20%。

**如果单独计税：**

36,000÷12 = 3,000，落在按月换算后的3%档、速算扣除数0：

> 36,000×3% − 0 = **1,080元**

**两者相差 6,120元。** 选单独计税，这36,000只交1,080；并入则要交7,200，多交6,120。

---

## 两个值得留意的点

**1. 36,000这个数卡得很巧，刚好是单独计税3%档的上限。** 如果公司多发1元（36,001），除以12就超过3,000，整笔奖金跳到10%档：36,001×10%−210 = 3,390.1元，比1,080多交2,310元。所以如果HR问你奖金数额能不能微调，**36,000是这道坎上的最优值**，别再往上加一点点。

**2. 操作上要盯住“申报环节”。** 单独计税是公司在代扣代缴时申报的，一旦按并入报了，年度汇算时**改不回来**；反过来，如果公司按单独扣了，你汇算时可以在个税APP“工资薪金”项下的“奖金计税方式选择”里改成并入（[天津税务答疑](https://tianjin.chinatax.gov.cn/11200000000/0300/030005/p20260512085922908.shtml)）。所以发放前跟HR或财务确认一句：年终奖按全年一次性奖金单独计税申报。哪怕你不确定哪种划算，也先让他们按单独报，汇算时再比较、再改，这样两种选择都还在。

*前提说明：以上按你给的“扣完五险一金、减除费用和专项附加扣除后约18万”计算，且假设没有其他综合所得。18万是个约数，但只要实际落在14.4万到26.4万之间，这36,000并入后都完整适用20%税率，多交7,200这个结论不变。最终以个税APP汇算结果为准。*
