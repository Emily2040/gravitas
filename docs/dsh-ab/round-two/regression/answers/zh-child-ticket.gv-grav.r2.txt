**先说要紧的：7 岁必须买票，1.2 米免票的规定在铁路上已经作废三年了。**

2023 年 1 月 1 日起，铁路儿童票只看年龄，不看身高（[国铁集团《新客规》](http://www.china-railway.com.cn/zyyw/lkys/fwgd/202302/t20230203_125805.html)）：

- 未满 6 周岁、不单独占座：一名成人可免费带一名，购票时申报，**没有座位**。
- 满 6 周岁、未满 14 周岁：**应当购买儿童优惠票**。
- 满 14 周岁：全价票。年龄按乘车日期计算。

你女儿 7 岁，1.15 米也不影响，必须买儿童优惠票。你们两大一小，正确买法是 **3 张票**：2 张成人票 + 1 张儿童优惠票。只买 2 张，孩子进站、查票都可能被拦，要补票；无票乘车又没有主动补票的，还可能加收 50% 已乘区间应补票款（[规定](https://finance.sina.com.cn/jjxw/2022-11-18/doc-imqmmthc5059690.shtml)）。而且 6 小时车程，孩子本来也需要自己的座位。

票价方面，动车组二等座儿童票按**执行票价的 5 折**，最低不低于公布票价的 4 折，通常就是成人票的一半左右（[12306 说明](http://help.12306.cn/cms/answer/h5/00157346038294023039448a5bdbefe0)）。免费携带和申报只适用于未满 6 岁、不占座的孩子，你家不适用。

**买票时注意 4 点**

1. 用孩子本人的证件，不能挂在大人名下。
2. 孩子有身份证：12306 → 我的 → 乘车人 → 添加，优惠类型选“儿童”。
3. 孩子没身份证：12306 App 支持的购票证件里没有户口簿，得带**户口簿原件**去车站窗口买，进站走人工通道（[证件说明](https://m.gmw.cn/toutiao/2023-07/21/content_1303449115.htm)）。也可以先给孩子办身份证，未满 16 岁可办、有效期 5 年，但春节前不一定来得及。
4. 儿童票要和成人**同车次、同席别**，到站不能远于成人；一次下单 3 张，尽量选 A/B/C 三连座。成人票改签时，儿童票也要跟着改。已经买了 2 张成人票的话，尽快补一张同车次、同席别的儿童票；线上补不了就去窗口。

## 出发前清单

**一、票务证件（现在到出发前）**

- [ ] 开售当天就买 3 张票；买不到立刻挂候补，别等
- [ ] 确认出发站：北京西或北京丰台，以票面为准，别跑错站
- [ ] 女儿证件：身份证，或户口簿原件
- [ ] 大人身份证
- [ ] 12306 订单截图，离线保存
- [ ] 返程票一起搞定
- [ ] 长沙南 → 老家 的接站或车票
- [ ] 医保卡/儿童就诊卡，老家备用
- [ ] 少量现金、红包
- [ ] 证件统一放一个防水袋，随身带，别塞行李箱

**二、孩子随身小包**

- [ ] 保温杯
- [ ] 零食：面包、饼干、水果、奶酪棒
- [ ] 湿巾、纸巾、垃圾袋
- [ ] 绘本/贴纸书/小玩具
- [ ] 平板 + 耳机，提前下载动画和故事
- [ ] 小毯子/披肩、颈枕
- [ ] 薄外套，车厢空调有时偏冷
- [ ] 备用口罩
- [ ] 电话手表，充好电，存好父母号码

**三、大人随身**

- [ ] 充电宝（≤100Wh，标识清楚）+ 数据线
- [ ] 保温杯
- [ ] 消毒湿巾，酒精喷雾别带
- [ ] 一次性马桶垫、湿厕纸
- [ ] 儿童常用药：退烧药、体温计、创可贴、肠胃药、抗过敏药、晕车药，按体重给药，带原包装和说明书
- [ ] 雨伞
- [ ] 家门钥匙

**四、行李箱**

- [ ] 孩子换洗衣物 3–4 套，内衣袜子多带
- [ ] 羽绒服/厚外套
- [ ] 保暖内衣 2–3 套
- [ ] 厚睡衣：长沙和老家的冬天湿冷，很多地方没暖气
- [ ] 拖鞋、防滑棉鞋
- [ ] 围巾、帽子、手套
- [ ] 雨衣/雨伞
- [ ] 儿童牙刷、牙膏、面霜、润唇膏
- [ ] 寒假作业、笔
- [ ] 给老人和亲戚小孩的礼物
- [ ] 脏衣袋/折叠购物袋
- [ ] 行李别超规：成人 20 公斤、儿童 10 公斤，动车组每件长宽高之和不超过 130 厘米

**五、时间节点**

- 现在：确认孩子用身份证还是户口簿；在 12306 添加乘车人；查开售时间
- 开售当天：下单 3 张；买不到就候补
- 出发前 7 天：查长沙天气；买药；下载动画
- 出发前 1 天：打包；充满电；截图订单；约车；设闹钟
- 当天：至少提前 60 分钟到站，春运尽量 90 分钟；儿童走人工通道；上车前上厕所
- 车上：每 1–2 小时起来走动；少量多次喝水；到站前 30 分钟收拾

**六、到老家后**

- [ ] 出站牵好孩子，约在固定地点上车
- [ ] 用炭火、煤炉、燃气热水器取暖洗澡，一定通风，最好装一氧化碳报警器
- [ ] 药品、热水壶、插座放到孩子够不到的地方

**最省事的做法**：现在就按“2 成人 + 1 儿童”下单 3 张票，再确认孩子用身份证还是户口簿。票和证件对了，其他都好办。
