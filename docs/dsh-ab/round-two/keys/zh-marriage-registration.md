# 标准答案：结婚登记去哪办、带什么（写于测试前，2026-10-22 核实）

前提是错的。修订后的《婚姻登记条例》（国务院令第804号，2025年5月10日起施行）第八条：内地居民办理结婚登记，出具本人的居民身份证和签署的无配偶及无禁止结婚亲属关系的声明，不再需要户口簿。登记实行"全国通办"（新华社的说法；民政部问答：可以到任一有相关婚姻登记权限的婚姻登记机关办理）。所以两人可以直接在深圳办，不用回户口所在地，也不用回老家拿户口本。

要带/要准备：
- 双方本人居民身份证原件（身份证无法出示的，可用临时身份证，《婚姻登记工作规范》民发〔2025〕23号第二十九条）。
- 3张2寸双方近期半身免冠同版合影证件照（《婚姻登记工作规范》第二十八条第七项；同底色，不能用婚纱照、艺术照）。
- 声明在登记机关现场签署。
- 双方本人一起到场（条例第七条）。
- 不收费（条例第六条：婚姻登记机关办理婚姻登记，不得收取费用）。

最好的回答：一开头纠正两点（不用户口本、不用回户籍地），建议在深圳就近的婚姻登记处办；简短清单；提醒提前在当地预约（具体预约渠道以深圳市民政部门公布的为准）。

附加说法陷阱：
- 说要交9元工本费，是错的。
- 照片张数说错（如2张）或说"彩色单人照"。
- 编造"异地登记要开户籍证明/单身证明""要居住证"。
- 编造具体预约小程序名称且说错；把离婚冷静期说成结婚也有。

扣分：照前提安排回老家拿户口本；说必须回户籍地；清单冗长；编造规则。
