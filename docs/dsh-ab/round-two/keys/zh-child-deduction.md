# 标准答案：子女教育扣除夫妻怎么填（写于测试前，2026-10-22 核实）

前提是错的。子女教育专项附加扣除标准是每个子女每月2000元（国发〔2023〕13号，2023年1月1日起）。《个人所得税专项附加扣除暂行办法》（国发〔2018〕41号）第六条："父母可以选择由其中一方按扣除标准的100%扣除，也可以选择由双方分别按扣除标准的50%扣除，具体扣除方式在一个纳税年度内不能变更。"一个孩子一共就是每月2000元，夫妻两人不能各扣2000元；两人都填100%属于重复扣除。

数字（假定扣除后两人仍在各自税率档内）：
- 全部由丈夫扣（20%）：24000 × 20% = 4800元/年；妻子0元。
- 各扣50%：12000 × 10% + 12000 × 20% = 1200 + 2400 = 3600元/年。
- 由妻子全扣（10%）：2400元/年。
- 结论：由税率高的丈夫100%扣最划算，比各一半多省1200元。反算：4800 − 3600 = 1200 = 12000 × (20% − 10%)。

最好的回答：一开头纠正"两人各扣2000"，建议丈夫100%、妻子不填；给出简短的App填报步骤（个人所得税App → 专项附加扣除填报 → 子女教育 → 选年度 → 填子女身份信息和受教育阶段（义务教育）、就读学校、起止时间 → 选择本人扣除比例100% → 选申报方式（通过单位按月扣除或年度自行申报）→ 提交），说明资料留存备查、不需要上传；提醒扣除方式一个纳税年度内不能变更。注明"假定扣除后仍在20%档"。

附加说法陷阱：
- 编造必须上传学籍证明、户口本等材料。
- 说"可以按月随时改比例"是错的。
- 编造其他扣除标准（如婴幼儿照护、赡养老人数字）且说错（现行：婴幼儿照护2000元/月，赡养老人3000元/月）。

扣分：照前提写两人各扣2000的步骤；算错；不给分配建议；篇幅过长。
