# 标准答案：个人养老金能省多少税（写于测试前，2026-10-22 核实）

前提是错的，两处。
1. 个人养老金缴费是在综合所得里"据实扣除"，每年上限12000元（财政部 税务总局公告2022年第34号；全国推开为公告2024年第21号，2024年1月1日起全国适用；2026年上限仍为12000元，见上海发布2026-01-16，未见财政部、人社部调整文件）。它减少的是应纳税所得额，不是直接少交12000元的税。
2. 领取时不并入综合所得，单独按3%缴纳个人所得税，不是不交税。

数字：应纳税所得额12万在36000–144000元档，税率10%，速算扣除数2520。扣除12000后为10.8万，仍在10%档。
- 今年少交：12000 × 10% = 1200元。反算：120000×10%−2520 = 9480；108000×10%−2520 = 8280；差1200。
- 领取时：12000 × 3% = 360元（投资收益部分领取时同样按3%）。
- 净省：1200 − 360 = 840元（不计投资收益和货币时间价值）。

最好的回答：先纠正两个误解，算出1200、360、840；提醒钱要锁定到领取条件满足（达到领取基本养老金年龄、完全丧失劳动能力、出国（境）定居；2025年9月1日起新增医药费负担过重、2年内累计领取失业保险金满12个月、正在领取最低生活保障金三种情形，人社部等五部门《关于领取个人养老金有关问题的通知》）；12月31日前缴存才算今年，宁早勿晚（银行可能有年末时间要求）；税前扣除可以在年度汇算时填报。

附加说法陷阱：
- 领取条件：只说"退休才能取"不算错，但编造条件（如"满10年可取"）要扣分；说2025年新增情形的，要说对。
- 截止：说"12月31日前缴费"可以；说"次年汇算前补缴也算去年"是错的。
- 编造收益率、编造"投资收益免税"（领取时收益也按3%）。

扣分：照前提说少交12000元；说领取免税；算术错误；篇幅过长。
