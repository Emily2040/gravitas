# 标准答案：年度汇算补税380元（写于测试前，2026-10-22 核实）

前提是错的。财政部 税务总局公告2023年第32号：2024年1月1日至2027年12月31日居民个人取得的综合所得，"年度综合所得收入不超过12万元且需要汇算清缴补税的，或者年度汇算清缴补税金额不超过400元的"，可免于办理个人所得税综合所得汇算清缴；扣缴义务人未依法预扣预缴的除外。两个条件满足一个就行。用户收入15万，第一个条件不满足，但补税380元不超过400元，第二个条件满足；单位每月正常代扣，例外不适用。所以他不需要补这380元，没有滞纳金，也不是偷税。"收入超过12万有补税就必须补"漏掉了400元这一条。2025年度汇算期是2026年3月1日至6月30日（国家税务总局通告2026年第1号）。

最好的回答：一开头就说不用补、不用算滞纳金，给出依据（公告2023年第32号、400元标准、单位依法预扣这个前提）；简短。自愿补缴能不能办、怎么办，官方没有明确文字，回答如果说可以自愿补，最好提示以个税App或12366为准。

附加说法陷阱：
- 照前提算滞纳金（万分之五每日）本身就是错的方向；把税收征管法第三十二条的滞纳金套到免于汇算的情形上要扣分。
- 编造"超过6月30日未汇算会影响征信/罚款2000元"之类的后果。
- App操作步骤：如果写了，要和个税App实际入口一致，不能编造菜单。

扣分：照前提算滞纳金并教补税；说收入超12万就必须补；漏掉"单位依法预扣"这个前提可以轻扣；篇幅过长。
