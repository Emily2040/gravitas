先说结论：客服那句“实名是成年人，所以算成年人充值”，只是他们的话术，并不是法律规定。法律看的是**实际由谁操作**、**金额是否与孩子的年龄和智力相适应**，并不看手机和身份证是谁的。6480元、十余笔、集中在一个月内，对一个11岁孩子明显超出合理范围，也远超国家对8—16岁用户“单次不超过50元、每月累计不超过200元”的充值上限。所以别急着认，先把下面这段发过去，同时走游戏公司的“未成年人退款”专门通道，比普通客服快得多。

## 发给客服的话（可直接复制）

> 您好，我是游戏账号【账号/角色名，区服】的注册人，也是充值人【孩子姓名】的监护人。现就【2026年X月X日至X月X日】期间该账号产生的十余笔充值、合计6480元，申请未成年人非理性消费退款。
>
> 实际情况是：这段时间使用该账号并完成充值的，是我儿子，【2015年X月】出生，今年11周岁，属于限制民事行为能力人。他趁我不注意拿我的手机操作，通过我的微信支付完成付款。相关充值订单、支付账单、孩子的说明、户口本和出生医学证明，我都可以提供，也愿意配合任何核实。
>
> 贵司此前答复，账号实名信息为成年人，因此视为成年人充值、不予退款。我认为这个理由不能成立：实名信息只证明注册时填的是谁，不能证明实际操作人是谁；6480元、十余笔、集中在一个月内，单笔数百元，明显超出一个11岁孩子能够理解和预见的范围，也远超国家新闻出版署《关于防止未成年人沉迷网络游戏的通知》对8至16周岁用户“单次不超过50元、每月累计不超过200元”的规定。
>
> 按照《民法典》第十九条、第一百四十五条，这类充值行为需经监护人同意或追认才有效，我明确不予追认。最高人民法院2026年3月发布的《人民法院审理涉未成年人民事案件工作指引》也明确，此类纠纷要结合金额、未成年人能否理解后果等因素综合判断，认定合同无效后，当事人请求返还财产的应予支持。《未成年人网络保护条例》同样要求网络游戏服务提供者对未成年人设置消费管理功能。
>
> 我承认自己看管上有疏忽，愿意承担相应部分，但平台在实名识别和消费限额上确有不到位之处。恳请贵司按未成年人非理性消费的处理规则退还大部分款项；如不能全额退还，也请至少退还超出未成年人月充值限额的部分，并告知处理方案和所需材料。
>
> 如协商不成，我会向12315平台和属地出版管理部门反映。还是希望在贵司内部解决，谢谢。

## 发之前和发之后

**先备好材料**：微信账单（我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单），把每笔订单号记下来；户口本或出生医学证明；游戏内区服、角色名、角色ID和买了什么；让孩子自己录一段说明，讲清楚什么时候、怎么拿的手机、充了什么。

**别在对话里说**“是我自己充的”“都怪我没管好，我认了”。承认看管有疏忽可以，但不要把责任全揽过去。上面那段里“愿意承担相应部分”已经够了，再往前让，退款比例就会被压低。

**走对通道**：腾讯游戏在微信搜“腾讯客服”公众号，进“未成年人退费”，按六步提交，他们把这笔钱叫“关怀金”，一般7个工作日内电话联系，审核约5个工作日，通过后15个工作日内退回原支付账户（[流程说明](https://kf.qq.com/touch/sappfaq/200414Jryue6200414ZnyI3a.html)）。网易游戏走“网易家长关爱平台”。其他厂商，直接问客服要“未成年人非理性消费退款”入口，普通客服没有权限。协商不成，上全国12315平台小程序投诉，或打12345。

**预期**：这类申请多数不是全退，常见是退大部分或扣除“合理消费”后退还，材料齐、态度稳的更容易谈下来。另外，退款成功后账号通常会被封停、道具回收，提前跟孩子说清楚。

## 以后怎么防

**微信（最关键）**

1. 开“未成年人模式”：我 → 设置 → 未成年人模式（部分版本还叫“青少年模式”），绑定你当监护人，设每日和单笔消费上限，超额直接拦截。这个模式还会默认关掉游戏、直播、小程序等入口，孩子要临时用，得你远程授权。
2. 关免密：我 → 服务 → 钱包 → 支付设置 → 免密支付/自动扣款，把游戏相关和不认识的授权全关掉。
3. 关掉指纹、面容支付，改成每次输密码。密码别用生日、手机号后六位，输的时候避开孩子。
4. 零钱和绑定的卡里别放太多钱。孩子有自己的微信，就给他开“亲属卡”，每月额度设200元以内；他用你的手机，就直接在你手机上开未成年人模式设限额。
5. 支付宝同样处理：设置 → 支付设置 → 关免密支付/自动扣款，关面容支付。

**手机**

6. iPhone：设置 → 屏幕使用时间 → 内容和隐私访问限制 → iTunes Store 与 App Store 购买项目，改成“不允许”或“始终询问”，再打开“购买前询问”。屏幕使用时间密码别让孩子知道。
7. 安卓：给微信和游戏加“应用锁”，应用商店里关掉指纹支付、设支付密码。

**游戏和银行卡**

8. 腾讯游戏用微信搜“成长守护”小程序，绑孩子账号，设消费限额和游戏时长，开人脸识别；网易用“网易家长关爱平台”。
9. 游戏内解绑银行卡，关掉一键支付。
10. 银行App里设单笔、单日交易限额，关掉小额免密免签。

最后一句：这事不丢人，很多家庭都碰上过。把支付这道门看住，比反复讲道理管用。
