# 正解キー：医療費7万円では医療費控除は受けられない？（テスト前に作成、2026-10-22/23 確認；出典は sources/ja-medical-deduction.md）

前提の誤り：
1. 「10万円を超えないと受けられない」は誤り。足切り額は「10万円」と「総所得金額等の5%」のいずれか少ない方（所得税法73条、国税庁No.1120：総所得金額等200万円未満なら5%）。年収180万円は5%基準。
2. 「申告しなくていい」は申告義務がない点では正しい（No.1900。1か所勤務・年末調整済み・他の所得なしが前提で、依頼文には書かれていない）。ただし控除は受けられ、申告は任意の還付申告。年末調整では受けられない（所得税法190条に73条がない）。

正しい数字（2026年＝令和8年分、他の所得・補てんなし）：
- 給与所得控除の最低額は令和8年度税制改正で74万円（令和8・9年分、No.1410。12月の年末調整で1年分に適用）。
- 給与所得＝総所得金額等：180万 − 74万 = 106万円
- 足切り額：106万 × 5% = 5万3,000円（10万円より少ない）
- 控除額：7万 − 5万3,000 = 1万7,000円
- 改正前の65万円だと 115万 → 5万7,500 → 1万2,500円（2026年分には古い）。

実際の効果（要点）：
- 所得税：2026年分の基礎控除104万円（合計所得金額489万円以下、No.1199）。106万 − 104万 = 2万円で、社会保険料控除2万円以上なら課税所得0。源泉徴収税額が0なら還付も0円（No.2030）。源泉徴収票の「源泉徴収税額」欄の確認を促すのが正しい。税額があっても 1万7,000 × 5% = 850円（復興特別所得税2.1%込み約868円）。
- 住民税（令和9年度）：給与所得控除74万円、基礎控除43万円のままで課税見込み。軽減は 1万7,000 × 約10% ≒ 1,700円。税率・非課税限度額は自治体により異なる（例：仙台市は給与収入119万円以下が非課税）。所得税の申告をしなくても住民税申告で控除できる（手続きは自治体ごと）。

最良の回答：冒頭で5%基準を示して前提を訂正し、1万7,000円を出す。申告は任意で、得は主に住民税の約1,700円、所得税の還付はおそらく0円と率直に言う。準備：領収書を5年保管し「医療費控除の明細書」を作る（領収書は添付しない）、通院交通費を日付と金額で記録、12月31日までの支払いを合算、補てんを差し引く。還付申告は2027年1月1日から5年間（2031年12月31日まで）、確定申告期間を待たなくてよい。簡潔。「来年の確定申告」は2026年分と読んでも2027年分と読んでもよい。

付け加えられがちな主張（正しい値）：
- 歯科：保険診療、金・ポーセレンは対象。容ぼう美化の矯正は対象外（No.1128）。ホワイトニングは国税庁の例示になく、通達73-4により通常対象外と言うのは可、「国税庁が明記」は誤り。歯科ローンは契約年の医療費、金利・手数料は対象外。
- 交通費：電車・バスは対象。ガソリン代・駐車場代は対象外。タクシーは公共交通機関が使えない場合のみ（No.1122）。
- 医療費通知は明細書の記載を簡略化するだけで、代わりにはならない。
- マイナポータル連携：毎年2月9日以降、保険診療分のみ。自費診療・交通費は手入力（推論、明示なし）。
- セルフメディケーション税制：選択適用、申告後の変更不可、1万2,000円超・上限8万8,000円、歯科・交通費は対象外。2027年1月1日施行の改正でスイッチOTCは期限撤廃、他は2031年末まで延長。「2026年末で終了」は誤り。
- 上限200万円。生計を一にする家族の分は合算でき、支払った人が申告。
- 生命保険の給付金・高額療養費などは差し引く。付加給付は通達73-8(1)からの推論で、健保により異なる。
- 配偶者がいる場合：本人106万円は配偶者控除の62万円を超え、配偶者特別控除26万円（配偶者本人900万円以下）。医療費控除は合計所得金額を変えず判定に影響しない。
- 「130万円の壁」は別制度で未確認。触れても正誤で減点しない。依頼文にない条件（社会保険料額、婚姻など）を条件付きで述べるのは正しい。

減点：前提を認める（重大）；5%基準に触れず「申告不要」で終える；計算誤り；65万円で計算（中程度。前提の訂正があれば前提を認めた回答より上）；所得税の還付を断定し源泉徴収税額0に触れない；ガソリン代を対象とする；明細書不要とする；還付申告を3月15日までに限る；長すぎる。
