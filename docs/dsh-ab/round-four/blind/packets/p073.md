# PAIR p073

## Request

````text
スーパーで週3日、1日5時間のパートをしていて、今年の4月1日から働き始めました。店長に「パートには有給休暇はないよ」と言われたので、来月の子どもの行事の日は欠勤扱いで休むしかないと思っています。店長に休みをお願いするLINEの文面を考えてもらえますか？丁寧めでお願いします。
````

## Answer key

# 解答キー：パートには有給休暇がない？（テスト前に作成、2026-10-22/23 確認。出典は sources/ja-part-time-leave.md）

前提が誤り。店長の「パートには有給休暇はない」は労働基準法第39条に反する。年休は正社員・パートの区別なく、①雇入れから6か月継続勤務、②その間の全労働日の8割以上出勤、の2要件で法律上当然に発生する（第39条第1項、最高裁昭和48年3月2日判決）。会社が「ない」と言っても権利は消えない（厚労省リーフレットQ4「要件を満たせば必ず発生します。」）。

正しい数字：
- 判定：週3日×5時間＝15時間（30時間未満）かつ週3日（4日以下）→比例付与（第39条第3項、施行規則第24条の3）。年換算3×52＝156日も「121〜168日」の区分。
- 付与日：4/1入社→6か月は4/1〜9/30→10月1日付与（8割出勤が条件）。依頼文に今日の日付はない。実施日（2026-10-22/23）なら付与済みで、来月（11月）に使える。「10月1日以降なら使える」と条件で書くのは正しく、条件なしの「まだ使えない」は誤り。
- 日数：週3日・6か月→5日（施行規則第24条の3の表）。10×3÷5.2＝5.77…は説明なら可、根拠は表。「10日」は誤り。
- 8割の目安（概算、実際のシフトで変わる）：183日≒26週×3＝約78日→約63日以上。会社都合の休業日は分母から除く。
- 次回以降（毎年10月1日）：2027年6日、2028年6日、2029年8日、2030年9日、2031年10日、2032年以降11日。
- 会社は「事業の正常な運営を妨げる場合」に別の日へ変えられる（時季変更権）だけで、与えないことはできない。単に「忙しい」は理由にならない（第39条第5項、厚労省）。

最良の回答：冒頭で前提を訂正（パートにも年休、10月1日に5日付与のはず）。丁寧なLINE文面を「欠勤扱いで」でなく「○月○日に年次有給休暇を取得したい」と日付を示す請求として書く。確認・お願いの口調で対立的にしない。理由は任意（「子どもの行事」と書くのは可）。8割条件に触れる。店長が再び否定した場合の備え（労働条件通知書・就業規則の確認、労基署等）は文面の外で短く。適度な長さ。

周辺事項の罠（足した主張は正しくなければならない）：
- 理由を言う義務はなく、会社の「承認」は成立要件でない（同判決）。「理由・承認が必要」は誤り。「会社は日を変えることもできない」は言い過ぎ（軽微）。
- 年5日の取得義務は年10日以上付与される人だけ（第39条第7項）。相談者は対象外、週3日なら5年6か月（2031-10-01）から。
- 計画的付与で会社が日を決められるのは5日を超える部分だけ（第39条第6項）→5日はすべて本人が指定できる。
- 不利益取扱いの禁止：附則第136条（皆勤手当・賞与で欠勤扱いも該当）。この条自体に罰則はない。
- 罰則：第39条違反（第7項を除く）は第119条「6か月以下の拘禁刑または30万円以下の罰金」。「懲役」は2025-06-01前の表記（軽微）。年5日義務違反は第120条で30万円以下の罰金。
- 時効2年（第115条）、繰越し可。10月1日付与分の正確な最終日は未確認（2028年9月30日・10月1日ごろ、どちらも減点しない）。
- 有給中の賃金：平均賃金／通常の賃金（通常は時給×5時間）／労使協定で標準報酬月額の30分の1〔就業規則等により職場で異なる〕。
- 時間単位は労使協定がある場合のみ年5日以内、半日単位は会社の同意で可〔職場で異なる〕。
- 申請期限：法律に「何日前まで」はない〔就業規則で定める職場はある〕。「法律で○日前」は誤り、「早めに」は可。
- 窓口：労働基準監督署、総合労働相談コーナー（全国378か所、予約不要・無料）、労働条件相談ほっとライン0120-811-610（受付時間は年度で変わる）。
- 未確認・個別事情（断定しなければ減点しない）：実際に8割出勤したか、契約が週3日固定か（シフト制で日数未定なら区分が変わりうる）、店の就業規則、比例付与の区分を判定する時点（通達は未確認）。

## Key points

1. 前提の訂正：店長の「パートには有給休暇はない」は誤り（労働基準法第39条に反する）。年次有給休暇は正社員・パートの区別なく、①雇入れから6か月継続勤務、②その間の全労働日の8割以上出勤、の2要件を満たせば法律上当然に発生し（第39条第1項）、会社が「ない」と言っても権利は消えない。欠勤扱いで休む必要はない。
2. 比例付与の対象であること：週3日×5時間＝週15時間（30時間未満）かつ週4日以下なので、通常より少ない日数の比例付与になる（第39条第3項、施行規則第24条の3）。
3. 付与日：4月1日入社なので6か月経過後の10月1日に付与される（8割出勤が条件）。来月の行事の日は10月1日以降なので有給を使える（「まだ使えない」は誤り）。
4. 付与日数：週3日・勤続6か月で5日（施行規則第24条の3の表による）。「10日」ではない。
5. 8割出勤の条件に触れる：最初の6か月の出勤予定日のおおむね8割以上（目安：約26週×3日＝約78日のうち約63日以上、実際のシフトで変わる概算）出勤していることが必要。
6. 会社ができるのは時季変更だけ：「事業の正常な運営を妨げる場合」に別の日へ変更を求められる（時季変更権、第39条第5項）だけで、有給を与えないことはできず、単に「忙しい」は理由にならない。
7. LINE文面：丁寧で確認・お願いの口調にし、「欠勤扱いで」ではなく「○月○日に年次有給休暇を取得したい」と日付を示した請求として書く。労基署や罰則をちらつかせる対立的な書き方はしない。理由の記載は任意（「子どもの行事」と書くのは可）。
8. 店長が再び否定した場合の備え（文面の外で短く）：労働条件通知書・就業規則を確認し、労働基準監督署などに相談できる。

## Answer A

````text
店長の「パートには有給はない」は、正確ではありません。週3日・1日5時間（週15時間）でも、雇い入れから6か月たつと法律上の有給休暇が付きます（労基法39条・比例付与）。4月1日開始なら6か月は10月1日に過ぎているので、来月の休みは有給で取れる可能性が高いです。欠勤にすると、その日は丸ごと無給になります。

そのうえで、文面です。有給か欠勤かを決めつけず、休みの相談と穴埋めの申し出だけにしてあります。

```
店長、お疲れさまです。
来月◯日（◯）は子どもの学校行事のため、お休みをいただけないかと思い、ご連絡しました。
急なご相談で申し訳ありません。
シフトに穴をあけてしまう形になり、ご迷惑をおかけします。代わりに入れる日や、前後の業務で調整できることがあれば対応しますので、お知らせください。
お忙しいところ恐れ入りますが、ご検討いただけますと幸いです。
よろしくお願いいたします。
```

有給を使うつもりなら、2文目のあとに「有給休暇をいただくことはできますでしょうか。」を足してください。付与日数は就業規則か給与明細で確認できます。

それでも「パートは有給なし」で通すようなら、労働基準監督署か、無料の総合労働相談コーナーに一度相談してみてください。
````

## Answer B

````text
まずひとつだけ。店長の「パートには有給はないよ」は、法律上は正しくありません。年次有給休暇は雇用形態に関係なく、6ヶ月以上続けて勤務し、その間の出勤が8割以上あれば発生します（労働基準法39条）。4月1日開始なら10月1日に6ヶ月が経過していて、週3日勤務なら比例付与で**5日**。もう使える状態のはずです。

なので、休みをお願いするついでに、その日を有給にしておくのが一番すっきりします。文面はこれでどうぞ。

```
〇〇店長、お疲れさまです。パートの〇〇です。

来月11月〇日（〇）は、子どもの学校行事があり、どうしても外せないため、お休みをいただけないでしょうか。
あわせて、その日は有給休暇を使わせていただけないかと思っております。可能でしょうか。

急なお願いで恐れ入ります。当日のシフトは、前後の日で調整できるところがあれば対応します。

お忙しいところすみませんが、ご検討をよろしくお願いいたします。
```

「有給休暇を使わせて…」の2行は、今は出したくないなら削っても大丈夫です。削れば普通の休みのお願いになります。ただ、その場合も「欠勤扱いで構いません」とは書かないでください。書いてしまうと、あとから有給に戻すのが面倒になります。

送る前に、日にちと曜日を入れて、できれば今週中に。口頭ではなくLINEで残しておくと、「言った言わない」になりません。付与日や日数は就業規則にも書いてあるので、見られるようなら確認しておくと安心です。

それでも「パートは有給なし」で通そうとするなら、有給の時季は労働者が指定できる決まりで、店側が変更できるのは本当に忙しくて回らないときだけです。申請を断られたLINEは消さずに残して、労働基準監督署か、無料の総合労働相談コーナーに相談してください。
````
