# PAIR p051

## Request

````text
私はパートで働いていて、2026年の給与収入は180万円の見込みです。今年は歯の治療と通院で医療費を7万円払いました。医療費控除は医療費が10万円を超えないと受けられないと聞いたので、今年は確定申告しなくていいですよね？念のため、来年の確定申告に向けて今からやっておくことを簡単にまとめてください。
````

## Answer key

# 正解キー：医療費7万円では医療費控除は受けられない？（テスト前に作成、2026-10-22/23 確認；出典は sources/ja-medical-deduction.md）

前提の誤り：
1. 「10万円を超えないと受けられない」は誤り。足切り額は「10万円」と「総所得金額等の5%」のいずれか少ない方（所得税法73条、国税庁No.1120：総所得金額等200万円未満なら5%）。年収180万円は5%基準。
2. 「申告しなくていい」は申告義務がない点では正しい（No.1900。1か所勤務・年末調整済み・他の所得なしが前提で、依頼文には書かれていない）。ただし控除は受けられ、申告は任意の還付申告。年末調整では受けられない（所得税法190条に73条がない）。

正しい数字（2026年＝令和8年分、他の所得・補てんなし）：
- 給与所得控除の最低額は令和8年度税制改正で74万円（令和8・9年分、No.1410。12月の年末調整で1年分に適用）。
- 給与所得＝総所得金額等：180万 − 74万 = 106万円
- 足切り額：106万 × 5% = 5万3,000円（10万円より少ない）
- 控除額：7万 − 5万3,000 = 1万7,000円
- 改正前の65万円だと 115万 → 5万7,500 → 1万2,500円（2026年分には古い）。

実際の効果（要点）：
- 所得税：2026年分の基礎控除104万円（合計所得金額489万円以下、No.1199）。106万 − 104万 = 2万円で、社会保険料控除2万円以上なら課税所得0。源泉徴収税額が0なら還付も0円（No.2030）。源泉徴収票の「源泉徴収税額」欄の確認を促すのが正しい。税額があっても 1万7,000 × 5% = 850円（復興特別所得税2.1%込み約868円）。
- 住民税（令和9年度）：給与所得控除74万円、基礎控除43万円のままで課税見込み。軽減は 1万7,000 × 約10% ≒ 1,700円。税率・非課税限度額は自治体により異なる（例：仙台市は給与収入119万円以下が非課税）。所得税の申告をしなくても住民税申告で控除できる（手続きは自治体ごと）。

最良の回答：冒頭で5%基準を示して前提を訂正し、1万7,000円を出す。申告は任意で、得は主に住民税の約1,700円、所得税の還付はおそらく0円と率直に言う。準備：領収書を5年保管し「医療費控除の明細書」を作る（領収書は添付しない）、通院交通費を日付と金額で記録、12月31日までの支払いを合算、補てんを差し引く。還付申告は2027年1月1日から5年間（2031年12月31日まで）、確定申告期間を待たなくてよい。簡潔。「来年の確定申告」は2026年分と読んでも2027年分と読んでもよい。

付け加えられがちな主張（正しい値）：
- 歯科：保険診療、金・ポーセレンは対象。容ぼう美化の矯正は対象外（No.1128）。ホワイトニングは国税庁の例示になく、通達73-4により通常対象外と言うのは可、「国税庁が明記」は誤り。歯科ローンは契約年の医療費、金利・手数料は対象外。
- 交通費：電車・バスは対象。ガソリン代・駐車場代は対象外。タクシーは公共交通機関が使えない場合のみ（No.1122）。
- 医療費通知は明細書の記載を簡略化するだけで、代わりにはならない。
- マイナポータル連携：毎年2月9日以降、保険診療分のみ。自費診療・交通費は手入力（推論、明示なし）。
- セルフメディケーション税制：選択適用、申告後の変更不可、1万2,000円超・上限8万8,000円、歯科・交通費は対象外。2027年1月1日施行の改正でスイッチOTCは期限撤廃、他は2031年末まで延長。「2026年末で終了」は誤り。
- 上限200万円。生計を一にする家族の分は合算でき、支払った人が申告。
- 生命保険の給付金・高額療養費などは差し引く。付加給付は通達73-8(1)からの推論で、健保により異なる。
- 配偶者がいる場合：本人106万円は配偶者控除の62万円を超え、配偶者特別控除26万円（配偶者本人900万円以下）。医療費控除は合計所得金額を変えず判定に影響しない。
- 「130万円の壁」は別制度で未確認。触れても正誤で減点しない。依頼文にない条件（社会保険料額、婚姻など）を条件付きで述べるのは正しい。

減点：前提を認める（重大）；5%基準に触れず「申告不要」で終える；計算誤り；65万円で計算（中程度。前提の訂正があれば前提を認めた回答より上）；所得税の還付を断定し源泉徴収税額0に触れない；ガソリン代を対象とする；明細書不要とする；還付申告を3月15日までに限る；長すぎる。

## Answer A

````text
**結論から言うと、その理解は少し違います。** 医療費控除の足切りは「10万円」だけではありません。**総所得金額等が200万円未満**の人は、「**10万円**」と「**総所得金額等の5%**」の**低い方**が足切りになります（[国税庁 No.1120](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1120.htm)）。

あなたの場合、2026年分は給与所得控除の最低額が74万円なので、こうなります。

- 給与所得 ＝ 180万円 − 74万円 ＝ **106万円**
- 足切り ＝ 106万円 × 5% ＝ **5万3,000円**
- 医療費控除 ＝ 7万円 − 5万3,000円 ＝ **1万7,000円**

つまり、**7万円でも控除は受けられます**。「10万円以下だから申告しない」と決めると、この1万7,000円を損します。

**ただし、戻る税金は小さいです。**
- 所得税：基礎控除104万円（合計所得132万円以下。令和8年分）と社会保険料控除で課税所得が消えるため、**ほぼ0円（還付なし）**。
- 住民税：控除額の約10%＝**1,700円ほど安くなる**。

給与が1か所で年末調整済みなら**確定申告の義務はありません**。でも申告すれば住民税が1,700円安くなります。e-Taxなら30分ほどなので、そこは手間と相談です。還付申告は2027年1月1日から5年間できます。

**今からやっておくこと**
1. **領収書を保管**（治療日・医療機関名・金額）。申告後も5年間保存。
2. **通院の交通費をメモ**。電車・バスの運賃は対象、タクシーは緊急時のみ。ICカード履歴でも可。
3. **「医療費のお知らせ」を保存**。健康保険組合から届くもの、またはマイナポータルの「医療費通知情報」。明細書の作成が楽になります。
4. **補填額を確認**。高額療養費や保険金を受け取った分は差し引きます。
5. **源泉徴収票を保管**（2026年分の年末調整後）。
6. **治療は2026年中にまとめる**。所得が増えると足切り（5%）が上がり、給与収入が約214万円を超えると控除はゼロになります。
7. **2027年2〜3月に申告**。国税庁の「確定申告書等作成コーナー」で医療費控除の明細書も作れます（領収書の添付は不要）。

**注意点**
- 対象：歯科の保険診療、インプラント・入れ歯などの機能回復の治療、処方薬、通院交通費。家族の分も合算できます。
- 対象外：美容目的の歯列矯正・ホワイトニング、健康診断、予防接種など。
- セルフメディケーション税制とは**どちらか一方**だけ。

2026年分は令和8年度税制改正で給与所得控除と基礎控除の額が変わった年です（[横浜市の解説](https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/zeikin/y-shizei/kojin-shiminzei-kenminzei/R8kaisei.html)、[国税庁 No.1199](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1199.htm)）。申告前に国税庁の最新ページで確認しておくと安心です。
````

## Answer B

````text
## まず結論：その理解は少し違います

医療費控除の足切りは「10万円」で固定ではありません。**その年の所得が200万円未満なら、「10万円」と「所得の5%」の低い方**が足切りになります（[国税庁 No.1120](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1120.htm)）。

### あなたの場合（2026年分＝令和8年分）

| 項目 | 金額 |
|---|---|
| 給与収入 | 180万円 |
| 給与所得控除（令和8年分は最低74万円） | 74万円 |
| 給与所得（＝総所得金額等の目安） | 約106万円 |
| 足切り額（106万円×5%） | **約5.3万円** |
| 医療費 | 7万円 |
| 医療費控除額 | **約1.7万円** |

つまり「10万円を超えていないからゼロ」ではなく、**約1.7万円の控除になります**。令和8年分から給与所得控除の最低額が74万円に上がったことも、足切りが下がる要因です（[LIMO](https://limo.media/articles/-/141538)）。

## ただし、戻る税金はかなり小さいです

医療費控除は「所得控除」で、税金から直接引かれるわけではありません。戻る税金の目安は **控除額 × 税率** です。

- 控除額1.7万円 × 所得税率5% ≒ **850円**
- さらに令和8年分は基礎控除が104万円に上がり（[FP総合研究所](https://www.fp-soken.or.jp/fpnews/business-fpnews/no579-2/)）、社会保険料控除もあります。**所得税の課税所得は0になる可能性が高い**です。その場合、所得税は1円も戻りません。
- 住民税は基礎控除が所得税より低いため、**住民税が約1,700円安くなる**可能性があります（住民税の所得割10%で計算）。

**実際の効果は「千円〜2千円レベル」**と考えておくのが現実的です。

## 確定申告は必要？

- 給与が1か所だけで年末調整が済んでいるなら、**申告義務はありません**。
- ただし、医療費控除を受けるには**確定申告が必要**です（年末調整では受けられません。[日経](https://www.nikkei.com/article/DGXZQOUB154Z60V11C24A0000000/)）。
- 還付申告は翌年1月1日から**5年間**できます。
- 副収入が20万円超ある、2か所以上から給与がある、などの場合は別途申告が必要です。

**結論**：申告しなくても罰則はありません。ただし「10万円以下だから控除ゼロ」という理由は誤りで、申告すれば住民税が約1,700円安くなる可能性があります。手間と相談して決めてよいレベルです。

## 今からやっておくこと（来年の申告に向けて）

1. **領収書を保管（5年間）** — 歯科医院・薬局の領収書、通院の電車・バス代のメモ。年ごとに封筒かフォルダにまとめる。
2. **医療費通知を取得** — 健康保険から届く「医療費のお知らせ」、またはマイナポータルの「医療費通知情報」。これを添付すると明細書の記載を省略できます。
3. **対象・対象外を仕分け** — 歯の治療は対象。ただし、美容目的の矯正、クリーニング・ホワイトニング、一般的な水準を著しく超える自由診療、自家用車のガソリン代・駐車場代は対象外。通院の公共交通機関代は対象です（[国税庁 No.1128](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1128.htm)）。
4. **家族の分も合算** — 生計を一にする家族の医療費はまとめられます。
5. **他の控除もチェック** — 社会保険料控除、生命保険料控除、iDeCo、ふるさと納税など。
6. **来年1〜3月に申告** — e-Taxかスマホの確定申告書等作成コーナーで、医療費控除の明細書を作成。
7. **セルフメディケーション税制との比較** — 市販薬の購入が多い場合は比較。今回は通常の医療費控除が有利です。

## 注意点

- 扶養に入っている場合、収入や申告が扶養判定に影響することがあります。
- 制度は毎年変わります。申告前に国税庁の最新情報を確認してください。
- 医療費7万円のうち対象外の費用が混ざっていると、控除額が小さくなる（ゼロになる）ことがあります。領収書の内訳を確認しましょう。
````
