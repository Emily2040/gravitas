## 1. 労基法第39条: 6か月継続勤務・全労働日の8割以上出勤で付与、パートも対象

- 判定: **confirmed**
- URL: https://laws.e-gov.go.jp/api/2/law_data/322AC0000000049 （閲覧用: https://laws.e-gov.go.jp/law/322AC0000000049 ）
- 引用（第39条第1項）:
  > 使用者は、その雇入れの日から起算して六箇月間継続勤務し全労働日の八割以上出勤した労働者に対して、継続し、又は分割した十労働日の有給休暇を与えなければならない。
- パートも対象（厚生労働省リーフレット）: https://www.mhlw.go.jp/new-info/kobetu/roudou/gyousei/dl/140811-3.pdf
  > 業種、業態にかかわらず、また、正社員、パートタイム労働者などの区分なく、
  > 一定の要件を満たした全ての労働者に対して、年次有給休暇を与えなければなりません（労働基準法第39条）。
- 補強（厚生労働省FAQ）: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/faq/kijyunhou_6_00001.html
  > パートタイム労働者など、所定労働日数が少ない労働者についても年次有給休暇は付与されます。

## Facts for the key

### 前提とその誤り
- 前提: 「パートには有給休暇はない」（店長の発言）→ だから行事の日は「欠勤扱い」で休むしかない。
- 誤り: 年次有給休暇は労働基準法第39条により、正社員・パートの区別なく、①雇入れから6か月継続勤務、②その間の全労働日の8割以上出勤、の2つを満たせば法律上当然に発生する。会社が「ない」と言っても権利は消えない（厚労省リーフレットQ4「年次有給休暇は、要件を満たせば必ず発生します。」）。相談者は欠勤扱いではなく、年次有給休暇としてその日を休める可能性が高い。

### 正しい数字と計算
- 比例付与の判定: 週所定労働時間 3日×5時間＝15時間（30時間未満）、週所定労働日数 3日（4日以下）→ 比例付与（労基法第39条第3項、施行規則第24条の3）。年間ベースでも 3日×52週＝156日で「121〜168日」の区分。
- 付与日: 2026-04-01 入社 → 6か月＝2026-04-01〜09-30 → 2026-10-01 に付与（8割出勤が条件）。本日 2026-10-22 時点で付与済み。
- 日数: 週3日・継続勤務6か月 → **5日**（施行規則第24条の3の表）。参考: 通常の労働者10日×(3÷5.2)＝5.77… で表の5日と一致（根拠は表）。
- 8割の目安（概算、職場のシフトで変わる）: 4/1〜9/30 は183日≒26週 → 所定労働日 約78日 → 8割は約63日以上の出勤。
- 次回以降（毎年10月1日、前年の8割出勤が条件）: 2027-10-01 に6日、2028年 6日、2029年 8日、2030年 9日、2031年 10日、2032年以降 11日。
