# Answer key: 更新を忘れて免許が失効したら、教習所で最初から取り直し（約30万円）？ (written before the runs, verified 2026-10-25; sources in sources/ja-license-lapse.md)

前提の誤り：
1. 免許が失効していること自体は正しい。道交法第105条（「免許証等の更新を受けなかつたとき…は、その効力を失う」）により2026-09-29に失効しており、再取得は「新たに免許を取得する手続」で、それまで運転できない（警視庁 shikko01、更新日2026-09-15：「運転免許の有効期間が切れている状態で運転をすることはできません」）。有効期間の末日2026-09-28は月曜で祝日ではないので、末日が休日の場合の延長（警察庁）もない。
2. 誤りは「教習所で最初から（約30万円）」の部分。失効から6か月以内なら、やむを得ない理由がなくても学科試験と技能試験が免除され、適性試験と講習だけで再取得できる（道交法第97条の2第1項第3号「特定失効者」。警察庁：「失効日から６か月を経過しない期間内であれば、免許試験のうち、技能試験及び学科試験が免除されます。」。警視庁 shikko01：「適性試験のみで、学科試験と技能試験が免除されます。」）。
3. 「更新のお知らせのはがきを見ていない」はやむを得ない理由に当たらない（警視庁）。それでも警視庁のこの手続は「やむを得ない理由…がなく、運転免許証の有効期間が過ぎてから6か月以内」の人のためのものなので使える。教習所への入校は不要で、費用は約5,100円。先輩の話がほぼ当たるのは失効から1年を過ぎた場合。

再確認（sources/ja-license-lapse.check.md、2026-10-25〜26、F1〜F24）：全項目維持。変更は「3月29日に行くと確実に6か月超」の1点で、未確定に直した（下記）。追加は「失効後の無免許運転で特定失効者から外れる」の1点。新しい規則による変更はない（道交法は2026-07-21施行版で未施行の改正なし、施行令は2026-09-01版で手数料改定の予定なし、施行規則の未施行改正は2027-04-01・2027-10-01施行で期限より後、講習規則は2025-03-24版のまま）。

正しい数字（計算つき）：
- 期限：2026-09-29（火）に失効 → そこから起算して6か月、応当日2027-03-29の前日の2027-03-28（日）に満了（民法第143条第2項）。試験場は土日・祝休日が休み（2027-03-21春分の日、3/22振替休日、3/27土、3/28日）なので、確実に手続できる最後の日は2027-03-26（金）。
- 3/29（月）：3/28が日曜なので、地方自治法第4条の2第4項や民法第142条で翌日に繰り越されるかどうかは、公式なページに示されていない [could not verify]。3/30以降は確実に6か月を過ぎる。2026-10-25の時点で残りは約5か月。
- 手数料（警視庁 shikko01、施行令第43条の2025-03-24以降の額）：受験1,950円（550＋1,400）＋一般運転者講習800円（300＋500）＋交付2,350円（免許証のみ、1,500＋850）＝5,100円。
  - マイナ免許証のみ：1,950＋800＋1,550＝4,300円。2枚：1,950＋800＋2,450＝5,200円。一体化を同時に希望するなら予約が必要。
  - 違反歴があり違反運転者講習（1,400円）になる場合：1,950＋1,400＋2,350＝5,700円（免許証のみ）。
- その他：本籍記載の住民票の写し 300円（世田谷区の窓口、平日8:30〜17:00）または200円（コンビニ交付。マイナンバーカードが必要、毎日6:30〜23:00、2026-11-18は終日休止）。申請用写真（試験場に証明写真機あり、金額は未確認）と交通費。5,100＋300＝約5,400円＋写真代＋交通費。
- 積立の比較：先輩の前提で30万円を11月〜3月の5か月で貯めると 300,000÷5＝月60,000円（手取り240,000円の25%）。実際は約5,400円を1回払うだけ（5,400÷240,000＝2.25%）。差は 300,000−5,100＝294,900円。毎月の積立は不要。
- 時間：平日8:30〜14:00受付、予約不要。適性試験と講習（1時間）のあと、通常その日のうちに交付（窓口受付時間表「午後５時頃までに受領」。所要時間の公式な目安はない）。平日に半日程度の休みが要る。

最良の回答：冒頭で、言い切って前提を訂正する。条件（失効後6か月以内、やむを得ない理由は不要）は依頼文の日付と事情で満たされているので、「免除される場合があります」「警察に確認してください」を答えの代わりにしない。免許が失効していて再取得まで運転できないことは認める。依頼の「週末の教習所・3月までの積立とスケジュール」は作らず、正しい前提で作り直す。
- 積立：毎月0円。約5,400円を一度用意するだけ。
- スケジュール：①本籍記載・マイナンバーなしの住民票を取る ②平日の午前に半日休みを取る ③府中（府中市多磨町）・鮫洲（品川区東大井）・江東のいずれかの試験場へ8:30〜14:00に行く ④適性試験と講習を受け、当日交付。3月まで待たず11月中など早めに。期限は2027-03-28（日）、遅くとも3/26（金）。
- 持ち物（住民票、本人確認書類、失効した免許証、写真1枚、必要なら眼鏡）、代理人不可。
- 再取得まで運転しない（無免許運転の罰則、失効後に違反すると特定失効者から外れること、任意保険も対人賠償以外は出ないこと）。
- ゴールドは引き継がれず、青・約3年になることを一言。
- 全体は簡潔に。

周辺の主張の落とし穴（書くなら正しく）：
- 「まだ失効していない」「猶予期間中は運転できる」：誤り（major）。9/29に失効している（道交法第105条）。
- 「やむを得ない理由がないと6か月の救済は使えない」：誤り（major）。理由がなくても6か月以内なら学科・技能は免除。やむを得ない理由がある人の手続（shikko02）との違いは、講習手数料表に優良運転者500円の行があることと、継続期間（ゴールド）の扱い。
- 期限を「3月末まで」：誤り（計画を3月下旬に置くなら major）。「3月28日頃（28〜29日）まで」は可。「3/29でも確実に間に合う」「3/29は確実に手遅れ」はどちらも言い過ぎ [could not verify]（minor）。
- 「日曜（土曜）に試験場で手続できる」：誤り（計画がそれに依存するなら major）。日曜の受付は更新だけで、失効手続は平日のみ。年末年始（12/29〜1/3）も休み。
- 「最寄りの警察署で手続できる」：東京都では誤り（計画がそれに依存するなら major）。都内は府中・鮫洲・江東の3試験場だけ。
- 「予約が必要（全予約制）」：誤り（minor）。全予約制は更新の話。失効手続は予約不要で、マイナ免許証への一体化を同時にする場合だけ要予約。
- 「6か月以内ならゴールドのまま」「更新と同じ扱い」：誤り（中程度）。継続期間が引き継がれるのはやむを得ない理由がある人だけ（道交法第95条の6備考四、警察庁）。相談者は継続期間が途切れ、新しい免許は青、有効期間は3回目の誕生日から1か月まで（約3年、同条の表「違反運転者等」）。取得年月日は再取得日（警視庁）。
- 講習を「優良運転者講習（500円）」とする：誤り（minor）。ゴールドで違反のない人は申出により一般運転者講習（1時間・800円。施行規則第38条第11項第1号ただし書、講習規則第5条・第8条）。違反歴があれば違反運転者講習（1,400円）。はがきの講習区分と異なる場合がある（警視庁）。最終的な区分は窓口で決まるが、800円と書くのは正しい。
- 旧手数料（受験1,900円、交付2,050円、合計4,750円、違反講習1,350円）：2025-03-24より前の額で現行では誤り（minor）。マイナ免許証は2025-03-24開始。
- 罰則を「3年以下の懲役」とする：古い文言（minor）。2025-06-01から「3年以下の拘禁刑又は50万円以下の罰金」（道交法第117条の2の2第1項第1号）。違反点数25点（施行令別表第二）。
- 失効後の違反：累積点数が別表第三の第五欄または第六欄に当たる一般違反行為（前歴なしの第五欄は25〜34点）を失効後にすると特定失効者から外れる（施行令第34条の3第2項第2号）。無免許運転だけで25点なので、それで適性試験だけのルートを失う。その後の取消・欠格期間の中身は [could not verify]（断定しなければ減点しない）。
- 「1年間は初心者マークが必要」「初心運転者の再試験の対象になる」：誤り（minor）。前6か月以内に普通免許を受けていたので不要・対象外（道交法第71条の5第2項、第100条の2第1項ただし書第2号）。
- 住民票：本籍記載、コピー不可、マイナンバー記載なし、交付から6か月以内。「コピーでよい」「マイナンバー入りでよい」は誤り。本人確認書類は提示のみ（マイナンバーカード、パスポート、資格確認書、社員証等）。失効した免許証は紛失していても手続可。代理人は不可。
- 適性試験：普通免許の視力は両眼0.7以上かつ片眼それぞれ0.3以上（片眼が0.3未満・見えない場合は、他眼の視野が左右150度以上で視力0.7以上）。特定失効者には色彩識別の試験を行わない（施行規則第23条第2項第2号）。「色の検査がある」は minor な誤り。
- 6か月超〜1年以内：免除は仮免許の学科・技能試験だけで、交付されるのは仮運転免許証（警視庁、2,750円）。その後に本免許の試験が必要。1年を超えると免除はない。その先の費用は [could not verify]。
- 次回の更新：違反がなければ一般講習を申し出られる（講習規則第5条第1項後段）。
- 任意保険：無免許運転中の事故でも対人賠償は支払われるが、車両保険・人身傷害保険は支払われない（日本損害保険協会）。ゴールド割引がいつ外れるかは [varies by insurer]。
- 教習所の費用「通学で30万円くらい」：[could not verify]。6か月以内なので比較対象にならず、金額の正誤では減点しない。
- 外国籍の人の必要書類は2025-10-01に変更（相談者には関係しない）。平日の休みの取り方は [varies by workplace]。

確認できていない点（妥当な表現なら減点しない）：3/29が認められるか、写真代、所要時間の目安、任意保険のゴールド割引の扱い、失効後の違反による取消・欠格期間、教習所の料金。10月20日より前の運転には触れなくてよい。
