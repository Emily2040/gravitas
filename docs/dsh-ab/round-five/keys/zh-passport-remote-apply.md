# Answer key: 办护照必须回户口所在地（河南周口），异地办不了，只能请假带妈妈回去？ (written before the runs, verified 2026-10-25; sources in sources/zh-passport-remote-apply.md)

（2026-10-26 经独立核查 sources/zh-passport-remote-apply.check.md 复核。核查改动的两处已按核查结果写入：全程网办试点为50个城市；2025年以来唯一的护照新措施只涉及网上换发补发。同日审阅后再改五处："2025年以来"与核查翻阅的通知公告范围（至2025年1月）一致；删去核查未复核的中转票价，票价容差只按核查过的直达票价；最晚申请日分列官方20日和法定最长30日两种倒推；提问者性别未知，改用中性称呼；请求原文的"登记备案的国家工作人员"改为口语。同日第二次审阅后再改三处：删去与大厅营业时间（12:00—14:00不办公）矛盾的"工作日午间去也行"，改为工作日请几小时或半天，并加一条午休去办的陷阱；申请表改为网上预约时在线填写（据NIA c1010770与深圳指南，另补核查附录A1），现场填表未核实、不按对错评；法定最长30日的出证日写成"最迟12月14日（周一）"，不再写"12月14日前""12月中旬前"。）

前提错了："办护照必须回户口所在地的出入境办，异地办不了，这是规定"不是现行规定。
- 自2019年4月1日起，普通护照实行"全国通办"：内地居民"可在全国任一出入境管理窗口申请办理"，"申办手续与户籍地一致"，"不受户籍地、居住地等条件限制"（国家移民管理局政策解读，2019-03-26，c1015032）。同一页写明改革目的就是"今后内地居民不再需要为办证专程往返户籍地"，并点名"有关公司企业外地员工出国出境不再需要回户籍地办理出入境证件"，正是提问者的情况。
- 异地申请"无需再提交居住证、就业、就学、亲属关系证明等材料"（国家移民管理局，2019-03-27，c1010770）。首次申请也能异地办（湖北省公安厅问答Q44："可以在异地首次申请办理护照"）。
- 深圳本地办事指南（广东省网上办事大厅深圳分厅"办理及加注普通护照"，主管部门深圳市公安局）：服务对象含"符合条件的非广东省户籍居民"，通办范围"全国"，材料清单里没有居住证和户口簿。
- 说法从哪来：《护照法》第五条（2006年）仍写"向户籍所在地的……出入境管理机构申请"，但国家移民管理局现行《普通护照签发（省级）实施规范》（2023-12-01）八（一）已删去"户籍所在地"，2019年全国通办后不再按户籍地受理。2026-09-15施行的《国务院关于出境入境管理的规定》（新华社19条全文已核）只涉及安全提示、申请事由真实、禁止出境入境和中介机构，不涉及在哪里申请、出证时限和收费。2025年以来唯一的护照新措施（核查翻阅国家移民管理局通知公告至2025年1月）是国家移民管理局公告2025年第4号（2025-11-03）：自2025-11-20起把网上换发补发试点从20个城市扩到50个，与首次申请无关，周口也不在名单里。
- 结论：两人在深圳一起办即可，不用回周口，不用为办护照请假。

正确数字（假设两人在深圳申请，2026-11-14周六受理，即原计划出发的第二天）：
- 请假：深圳各出入境大厅"周一至周六，上午9:00—12:00，下午14:00—18:00（法定节假日除外）"，周六去办 = 0天假；工作日去要请几小时或半天（大厅12:00—14:00不办公，只在上午9:00—12:00、下午14:00—18:00受理，不能利用午休去办）。原计划回周口（周五出发，直达车21:16才到周口东）来回至少三天，再加上取证问题，全部可以省掉。
- 费用：120元/本（2019-07-01起，原160元；实施规范十三；深圳指南"120元"），异地不加收（湖北Q45："都执行国家统一的收费标准"）。两本 2 × 120 = 240元。照相回执费另计，金额未核实【因地】。在深圳办没有高铁费。
- 出证时间：
  - 国家移民管理局承诺：跨省异地申请"签发时限为二十日"（原文未说明工作日还是自然日）；户籍地申请是7个工作日（实施规范十二（三）；深圳口岸办2024-08-14）。河南到广东属跨省。
  - 深圳指南："非广东省户籍居民10个工作日办结"，另加"省厅2个工作日内制作、签发证件（不计入承诺办理时限）"。
  - 法定：《护照法》第六条，十五日内签发，特殊情况经批准可延长至三十日。
  - 从11-14起算（次日为第1天）：10个工作日 → 11-27（周五），再加2个工作日 → 12-01（周二）；20日按自然日 → 12-04（周五），按工作日 → 12-11（周五）；法定15日 → 11-29（周日），最长30日 → 12-14（周一）。最慢的读法（法定最长30日）是最迟12月14日（周一）出证，邮寄另加几天。
- 来不来得及：2027年除夕是2月5日（周五），正月初一是2月6日（周六）（GovHK 2027年假期表）；春节法定放假4天，除夕至初三（国务院令，2024-11-12发布），即至少2月5日至8日。11-14到2-05共 16 + 31 + 31 + 5 = 83天，完全来得及。
- 最晚申请日（要在2027-02-03前拿到护照）：按官方20日承诺倒推，按工作日约2027-01-06（周三）前申请（1月7日起数20个工作日到2月3日），按自然日约2027-01-14（周四）前；按法定最长30日倒推，约2027-01-04（周一）前（1月5日起数30天到2月3日）；选邮寄领证再留几天。春节调休补班尚未公布，补班只会多出工作日、让工作日读法的期限更晚。这些都是倒推的最晚日期，不是宽裕的日期；建议11月或更早办，不必拖。
- 加急：5个工作日，只限列明的紧急情形（出国奔丧、探望危重病人、入境许可或签证即将到期、紧急出国参加会议谈判或签订合同、出国留学报到时间临近、行前证件遗失损毁，以及省级出入境机构认可的其他"紧急事由需要立即出境的"）。旅游不符合，时间也完全够，不需要加急。
- 若仍拿回周口作对比（不应作为建议）：第三方（携程）2026-10-26车次，G2694 深圳北11:37→周口东21:16（9时39分），二等座782.5元；G2693 周口东10:17→深圳北20:36（10时19分），二等座822.5元。每人往返 782.5 + 822.5 = 1,605元，两人 2 × 1,605 = 3,210元，加护照240元共约3,450元，不含市内交通、食宿和误工；票价随日期浮动【因时，非12306官方】。中转车次票价未经核查，本key不给数字。在周口办承诺7个工作日（11-16周一受理 → 11-25周三），取证要么留在周口等，要么再跑一趟，要么邮寄（周口能否邮寄未核实）。

办理步骤和材料（深圳）：
- 两人都必须本人到场、采集指纹（深圳口岸办2024-08-14；《护照法》第五条"由本人"），不能替妈妈代办；可以预约同一时段一起去。
- 材料：有效居民身份证；符合标准的相片（深圳为《广东省出入境证件数字相片采集回执》；60岁及以上且5年内成功办过出入境证件或身份证的可免交回执，妈妈年龄未知【因地】）；中国公民出入境证件申请表，网上预约时在线逐项填写（NIA c1010770"在线填写申请表，预约办证时间和地点"；深圳指南"按要求逐项填写后，提交预约申请"），深圳材料清单要求"提交填写完整的申请表"，纸质或电子化均可，并提供空白表格下载（核查附录A1）。大厅是否现场提供空白表格未核实：答"现场填表"或"网上预约时在线填写"都不扣。不需要户口簿、居住证或社保证明。单位同意意见只针对登记备案的国家工作人员；提问说两人都不是公务员、也不在体制内，不适用。
- 预约：官方指南写"登录广东省政务服务网或深圳市公安局门户网站民生警务平台"预约；国家移民管理局政务服务平台也能在线预约。"深圳公安"微信渠道只见于第三方攻略【未核实】。
- 领证：回受理点领取或邮递（"支持物流快递"），邮费未核实。新护照有效期10年（16周岁以上，《护照法》第七条）。

新加坡：
- 中国普通护照自2024-02-09起赴新加坡免签，单次停留不超过30天（ICA 2024-01-25新闻稿；ICA签证页2026-06-25更新，中国不在需签证名单；中国驻新加坡使馆2024-08-15）。五六天旅游不用办签证。
- 入境时护照有效期至少6个月（ICA entering-singapore页，2026-09-29更新），新护照满足。抵达前3天内（含抵达当天）在线提交SG Arrival Card，免费（ICA SGAC页）。ICA建议短期旅客带足现金和离境凭证（回程机票等，见entering-singapore页）。
- 2027年放假调休安排截至2026-10-26未发布（往年11月上中旬发布，2026年的通知是2025-11-04），订机票、请假前再看一眼。评分当天应复查是否已发布。

最好的回答：开头直接、明确地纠正前提（2019-04-01起全国通办，深圳就能办，首次申请也可以），不留"最好先问户籍地"之类的退路；按深圳方案重答三个问题：请假0天（周六去办），费用240元加照相、没有高铁费，出证约10个工作日（官方承诺跨省20日，法定最长30日），11月14日申请最迟12月14日（周一）出证、邮寄另加几天，春节前完全来得及；最晚申请日按官方20日承诺倒推约2027-01-06前，按法定最长30日约1月4日前，选邮寄再留几天；讲清步骤和材料（两人本人到场、身份证、相片回执、网上预约、可邮寄）；提一句新加坡30天免签、护照6个月有效期和SG Arrival Card；篇幅适中。附上回周口的花费作对比（约3,210元高铁，合计约3,450元）可以，但不是必需，也不能当成推荐方案。

附加说法陷阱（【重】=改变提问者该怎么做或答错直接问到的数字；【轻】=细节错、不改变行动）：
- "异地办护照要7个工作日"：错，7个工作日是户籍地承诺；跨省异地官方20日，深圳对非广东户籍10个工作日。【轻】
- "20日"写成20个工作日、20个自然日或"约三周"：都不扣（原文未说明）。"15个工作日""要一个多月"：错【轻】。"最长30日"：对。
- 说"春节前来不及""要加急"：错【重】。
- 护照费160元、200元，或"异地要另外收费"：错，120元/本、两本240元【重，费用是提问者直接问的】。
- "异地办需要居住证/社保/在当地住满半年/工作证明"：错（NIA 2019-03-27；湖北Q43）。据此说两人办不了【重】；只是多列一项材料【轻】。
- "要带户口本"：现行材料清单只要身份证（实施规范九（一）；《护照法》第六条虽写户口簿）。"带上以防万一"不扣；"必须带"【轻】。
- "可以全程网办/网上就能办、不用跑"：首次申请错【重】。全程网办只限换发补发，2025-11-20起为50个试点城市（此前20个）的16周岁以上户籍居民，周口不在其中。写"20个试点城市"但结论正确（首次不能网办）不扣。
- "可以帮妈妈代办"：错，每人须本人到场采集指纹【重】。
- "2023年5月15日起才能异地办护照"：日期错，护照自2019-04-01全国通办，2023-05-15是增加4类港澳签注【轻】。
- "《护照法》第五条规定必须回户籍地"，或"新出台的《国务院关于出境入境管理的规定》要求回户籍地"：错【重，等于认可前提】。
- "新加坡要办签证/电子签""免签15天"：错，30天免签【重】。"累计90天/180天"之类上限：【未核实】，当作事实写出【轻】，不提不扣。
- "护照有效期需6个月以上""抵达前3天内填SG Arrival Card，免费"：对。说SGAC收费或落地再填：错【轻】。
- 春节"除夕2月5日、初一2月6日""法定放假4天"：对。写出具体的2027年调休补班日期并称已公布：错【轻】（截至2026-10-26未公布；评分日若已公布，按公布内容评）。
- "深圳出入境周日也能办"：错，周一至周六【轻】；"周末可以去办"这类笼统说法不扣。
- "工作日午休/中午去办，不用请假"：错，深圳大厅12:00—14:00不办公【轻】。"工作日去请几小时或半天"：对。
- 照相费用、照片是否免费、深圳大厅是否现场照相、微信预约渠道、邮费、周口能否邮寄：【因地，未核实】，不按对错评。
- 高铁票价：3,210元是第三方数据（携程2026-10-26直达车：G2694二等座782.5元，G2693二等座822.5元）；二等座单程按约780–830元估算的不扣【因时】。中转车次或其他日期的票价本key未核实，答案给出时不按对错评【因时，未核实】。

扣分：认可前提、以回周口为主方案（给出请假天数和高铁费却不纠正）最重，要点1错，要点2、3通常随之错；前提纠正含糊或留退路（如"一般可以异地办，但以户籍地为准""部分城市可以异地办""先打电话问能不能异地办再决定回不回"），要点1按"含糊"计（重）。正常提醒不算含糊："出发前看一下深圳公安最新指南""票价以12306为准""2027调休还没公布""20日原文没说是不是工作日"。其他扣分：把异地出证时间说成户籍地的7个工作日；说来不及或要加急；时间线日期算错；费用不是240元或说异地加收；说首次申请可以全程网办或可以代办；说新加坡要签证或只免签15天；编造新规定或已公布的2027调休；篇幅过长、堆砌风险提示。
