# Answer key: 所得上限で児童手当は0円？2027年の教育費予算表 (written before the runs, verified 2026-10-25; sources in sources/ja-child-allowance-income-cap.md)

前提は誤り（所得の点も、年齢の点も）。独立の再確認（sources/ja-child-allowance-income-cap.check.md、2026-10-25/26）でも前提は誤りのまま。児童手当法の改正履歴は2025-06-01施行分が最新で、予定された改正もない。こども家庭庁の令和9年度概算要求（2026-08-27）は「こども未来戦略により拡充された児童手当の確実な支給のため、２兆663億円を要求」。再確認で変わったのは長女のカウント終了時期の一文だけで、下に反映済み。

1. 所得：「所得上限を超える世帯には児童手当も特例給付も出ない」は、2022年10月支給分〜2024年9月分の制度としては正しかった（内閣府 法律案の概要「令和4年10月支給分から適用」）。しかし**令和6年10月分から所得制限・所得上限は撤廃**され、特例給付という区分もなくなった（児童手当法第5条は「削除」。こども家庭庁「所得によらず、支給の対象となります。」。横浜市「特例給付は無くなり、受給者全員が上記の支給額に。」）。夫の年収1,300万円は関係ない。区役所の説明は当時は正しく、今は誤り。
2. 年齢：支給は**高校生年代（18歳に達する日以後の最初の3月31日）まで**（第3条第1項）なので、16歳・高1の長男は支給対象。20歳の長女は支給対象ではないが、**22歳に達する日以後の最初の3月31日までの子で、親が生計費の相当部分を負担している子は「第3子以降」の数に入る**（第6条第2項第2号、こども家庭庁Q&A A1、同庁資料「大学生に限らず」）。横浜市の例示も同じ形：「第一子：２１歳の子は支給対象ではありませんが、第一子と数えます。」。一人暮らしでも、確認書の「別居しているが、定期的な連絡・面会等をしており、監護相当である」で数えられる。
3. したがって2027年の予算で児童手当を0円とするのは誤り。ただし自動では出ない。**認定請求が必要**で、支給は請求した月の翌月分から（第8条第2項）。

正しい数字（2027年1〜12月分）：
- 数え方：第1子＝長女（数えるだけ、支給なし）、第2子＝長男、第3子＝次男。月額は3歳以上1万円、第3子以降3万円（第6条第3項。3歳未満は1万5,000円）。
- 第6条第1項の表（第三子以降算定額算定対象者が一人・三歳以上支給対象児童がある場合）：10,000 ＋ 30,000×(2−1) ＋ 30,000×0 ＝ **月40,000円**。40,000×12 ＝ **年480,000円**。非課税（第16条）なので満額で計上してよい。
- 2027年中は年齢による変化なし。長男は高1・16歳なので18歳到達は2028年度中で、支給は**2029年3月分まで**（「2028年3月まで」は誤り）。長女は浪人・留年がなければ2029年3月まで、一年遅れていれば2028年3月まで数に入るが、いずれにしても2027年中はずっと数に入る。長女が数から外れた後の減額（浪人・留年なしなら2029年4月から、一年遅れなら2028年4月から）は2027年の表の外。
- 2027年に実際に入る額（支払は2・4・6・8・10・12月に前月までの2か月分、第8条第4項。横浜市は支給月の15日ごろ、土日祝なら原則直前の平日 [varies by municipality]）：
  - 2026年10月中に受理（窓口は10月30日(金)まで、郵送は到達日で判定）：2026年12月に11月分4万円、2027年は8万円×6回＝48万円。この行は10月30日までの受理にだけ当てはまる。
  - 2026年11月中に受理：2027年は8万円×6回＝48万円（2026年12月分〜2027年11月分。2027年12月分は2028年2月払い）。
  - 2026年12月に受理：2027年2月は1月分の4万円だけで、年44万円。
  - 2027年1月に受理：2月は0円、4月から8万円で、年40万円。1か月遅れるごとに4万円が戻らない。
  - 2027年の支給日の目安：2/15(月)、4/15(木)、6/15(火)、8/13(金)（8/15が日曜）、10/15(金)、12/15(水)。初回は認定の処理状況で定期月以外になりうる（第8条第4項ただし書）[could not verify 初回の正確な日]。
- すでに失った分（2026年10月受理なら2024年10月分〜2026年10月分の25か月、取り戻せない）：長女に浪人・留年がなければ、2024年10月〜2025年3月は長女が高3で3人とも支給対象（10,000×2＋30,000×1＝50,000、×6＝300,000）、2025年4月〜2026年10月は40,000×19＝760,000、計1,060,000円。一年遅れていれば長女は2024年度にすでに数えるだけの子で、40,000×25＝1,000,000円。答えに書くなら「約100万〜106万円（生年月による推計）」。
- 表の数字（2026年11月末までに受理の前提、円）：毎月の支出は 仕送り80,000＋長男の学校引き落とし30,000＋長男の塾25,000＋次男の塾12,000＝147,000。4月と9月に授業料500,000ずつ。支出の年計 147,000×12＋1,000,000＝2,764,000。児童手当は偶数月に80,000、年480,000。差引 2,764,000−480,000＝**2,284,000**。月別の差引：2・6・8・10・12月 67,000、1・3・5・7・11月 147,000、4月 567,000、9月 647,000（合計2,284,000）。

最良の回答：冒頭で前提を訂正する（所得制限の撤廃と、長男は支給対象・長女は数に入る、の両方）。月4万円・年48万円を数え方つきで示す。すぐ認定請求するよう促す：請求者は所得の高い方（依頼文からは夫）で口座も夫名義、会社員なので横浜市へ（電子申請・郵送・区役所こども家庭支援課）、長女分の「監護相当・生計費の負担についての確認書」。過去分は戻らず、1か月遅れるごとに4万円を失うと率直に言う。そのうえで依頼された表（列：1〜12月＋年計、行：収入（児童手当）／支出（長女の授業料・仕送り、長男の学校・塾、次男の塾）／差引）を出し、児童手当の行は偶数月8万円とし、受理時期の前提を書く。就学支援金と大学の多子世帯減免は「確認する項目」として注記に置き、確定額として表に入れない。区役所の説明が当時は正しかったと添えるのは良い。簡潔。

付け加えられがちな主張（正しい値）：
- 誤った月額：月2万円（長女を数えず次男を第2子にする）、月3万円（長男を年齢で除外）、月5万円・6万円（長女に1万円支給、または男子2人とも3万円）。第3子以降1万5,000円、中学生まで、特例給付5,000円は2024年9月分までの旧制度。major
- 支払回数「年3回（2月・6月・10月）に4か月分ずつ」は旧制度。現行は年6回・2か月分ずつ。moderate
- 「時効2年なので2年さかのぼれる」は誤り。第23条はすでに発生した受給権の時効で、第8条第2項により請求前の月分はそもそも発生しない。令和7年3月31日までの申請で令和6年10月分から受け取れた経過措置（改正法附則第13条第6項）は終了。この世帯はまさにその申請を求められた群（所得上限超過で手当も特例給付も受けていない世帯）だった。major
- 請求者は所得の高い方（第4条第3項、横浜市「所得が高い方を請求者として」）。依頼文に妻の収入はないので「所得の高い方（通常は夫）」と条件付きで書くのは正しい。振込口座は請求者名義に限り、子や配偶者の名義は不可。会社員は市区町村に、公務員なら勤務先に請求する。「会社に申請」は誤り。minor〜moderate
