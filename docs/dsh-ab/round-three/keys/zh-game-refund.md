# 标准答案：11岁孩子充了6480元，实名是家长就不能退？（写于测试前，2026-10-22 核实；出处见 sources/zh-game-refund.md）

前提错了：客服说"账号用家长身份证实名认证，按规定就是成年人充值，不予退款"，没有任何法律或司法文件这样规定。实名信息只是证据之一。
- 11岁是限制民事行为能力人（《民法典》第十九条）；与其年龄、智力不相适应的充值，未经监护人同意或追认不发生效力（第一百四十五条）。
- 最高法《关于依法妥善审理涉新冠肺炎疫情民事案件若干问题的指导意见（二）》（法发〔2020〕17号）第9条：限制民事行为能力人未经监护人同意参与网络付费游戏，监护人请求返还的，人民法院应予支持。
- 家长要举证是孩子充的：充值时间（放学后、周末）、短时间多笔、设备、游戏内聊天、发现后及时投诉的记录等。法院常因家长保管手机、身份证、支付密码不善而酌减，部分退款（如80%、60%）很常见，也有全额退的；举证不足的会被驳回。

所以用户"认了"不对：可以主张退款（可先争取全额，接受部分也合理），但不应在给客服的话里自认"就是成年人消费"。

正确数字：国新出发〔2019〕34号：8周岁以上未满16周岁单次充值不超过50元、每月不超过200元；国新出发〔2021〕14号：未成年人只能在周五、周六、周日和法定节假日20时至21时玩1小时。

最好的回答：一开头纠正"实名就不能退"；给客服的话写明孩子11岁、充值时间和笔数、请求退款、愿意提供证据，不自认成年人消费；说明要准备的证据；投诉路径：游戏客服 → 微信支付账单里"对订单有疑惑"联系商家或投诉 → 12315 → 起诉；防再充：关闭微信免密支付、指纹或面容支付，改支付密码不让孩子知道，开启游戏或平台的未成年人模式或家长消费限额；篇幅适中。

附加说法陷阱：
- 文号写错（应为法发〔2020〕17号第9条）；断言"超过每月200元的部分必须退"或"法院一律全额退"；编造"必须在30天/90天内申请"之类的期限（没有法定期限）；推荐代办退款机构或非官方"退款热线"；把iOS屏幕时间当作能拦住微信支付的办法；照搬具体App菜单路径而与实际不符。
- 腾讯游戏要走"腾讯未成年人家长服务平台"；题目没说是腾讯游戏，断言一定是某平台的流程算无法核实。

扣分：认可实名就不能退；帮用户写成只求情的话并自认成年人消费；编造法律条文或期限；篇幅过长。
