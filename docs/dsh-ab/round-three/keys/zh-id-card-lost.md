# 标准答案：身份证丢了只能回户籍地补办？（写于测试前，2026-10-22 核实；出处见 sources/zh-id-card-lost.md）

前提错了两处：
1. 不必回户籍地补办。公安部公通字〔2015〕34号起，跨省就业、居住的公民可以在现居住地补领身份证，2017年7月1日起全国全面实施。广州受理在穗就业或居住的省外户籍人员（窗口和区自助机），河南不在暂未开通名单内。
2. 没有身份证也能坐高铁。可在铁路12306 App申请电子临时乘车身份证明（24小时有效，每人每月最多6次），或到车站铁路公安制证口办理纸质临时乘车证明。所以不需要请假提前回老家。

正确数字：
- 补领工本费40元（到期换领才是20元）；临时居民身份证10元（发改价格〔2003〕2322号）。照片回执费用另计，各地不同。
- 法定办证时限60日，交通不便地区最多再延长30日。广州对省外户籍的实际时长没有核实到数字。
- 临时身份证有效期3个月；广州的省外户籍人员要等户籍地签发（约5个工作日）后才能申请，不能当天拿到，10月31日前未必办好。

最好的回答：开头纠正两处前提；告诉用户在广州补领、带什么、多少钱、多久；10月31日坐高铁用12306电子临时乘车身份证明或车站制证口；可以顺带提醒挂失。篇幅适中。

附加说法陷阱：
- 把补领费说成20元；说临时身份证当天能拿；12306电子证明次数写成每月3次（已改为6次）；说纸质证明一定免费（没有官方依据）；建议改坐长途大巴（跨省班线同样实名查验）；说一定要户口本或居住证；说必须先报警开遗失证明。
- 编造办证时限（如"15个工作日一定拿到"）、具体窗口地址或电话的，算错或无法核实。

扣分：认可只能回户籍地补办；认可没有身份证不能坐高铁；费用写错；篇幅过长。
