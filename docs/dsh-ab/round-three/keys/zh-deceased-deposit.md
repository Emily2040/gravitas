# 标准答案：取已故父亲8600元存款必须公证？（写于测试前，2026-10-22 核实；出处见 sources/zh-deceased-deposit.md）

前提错了：柜台说"必须先办继承权公证"不对。银保监办发〔2021〕18号和金规〔2024〕6号（2024年6月1日起）：已故存款人在同一法人银行的账户余额合计不超过5万元的，配偶、子女、父母可以免公证直接申请提取（农村中小银行最迟2025年12月31日落实）。8600多元远低于5万元，不需要办继承公证。即使按旧标准（1万元），8600元也不需要公证。

谁办、带什么：妈妈或"我"任何一人即可（第一顺序继承人是配偶、子女、父母，《民法典》第一千一百二十七条；爷爷奶奶已故）。带：①死亡证明（如《居民死亡医学证明（推断）书》）；②亲属关系材料（户口簿、结婚证、出生证明等）；③申请人身份证；④申请人签名的承诺书（银行提供样本）。须一次性取出全部存款和利息并销户。银行向一名继承人支付即可，不需要全体继承人到场。

公证费：官方标准里没有"2%"。例如北京现行标准：财产继承20万元以下部分0.9%，不足200元按200元收；8600元按此最多200元。但本案根本不需要公证。

银行坚持要公证怎么办：向该行投诉；仍不解决可拨打金融监管总局消费投诉热线12378。

最好的回答：一开头纠正"必须公证"，说明5万元免公证政策；列出免公证要带的材料（而不是公证材料）；指出公证费2%不对或无需讨论；给出银行不认时的办法；篇幅适中。只说"1万元以下免公证"而不知道已提高到5万元，是小错（结论仍对）。

附加说法陷阱：
- 说只能取一部分或可以分次取；说要全体继承人到场；说5万元按单张卡算（应按同一法人银行所有账户合计）；把某地公证费标准说成全国统一；写继承份额而算错（若写：存款属夫妻共同财产的，先分一半给妈妈，余下由妈妈和"我"均分）；说必须先办遗产管理人。
- 编造具体文件号、热线、银行内部流程而与上面不符的，算错。

扣分：认可必须公证；只列公证材料；公证费按2%算并当真；篇幅过长。
