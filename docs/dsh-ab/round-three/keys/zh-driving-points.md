# 标准答案：学法减分把10分全减掉（写于测试前，2026-10-22 核实；出处见 sources/zh-driving-points.md）

前提错了两处：
1. 10分不可能全减掉。《道路交通安全违法行为记分管理办法》（公安部令第163号）第二十五条：一个记分周期内学法减分累计最高扣减6分。10分最多减到4分。
2. "减完就不怕再被扣"不对。剩4分时再扣8分就满12分；满12分要扣留驾驶证，参加满分学习和考试（第十七、十八条）。本周期减满6分后不能再减。另外，到清分日时记分未满12分且罚款已缴的，记分本来就会清零（第十五条）；学法减分的作用只是给剩下5个月多留余量。

正确数字（第二十七条）：
- 网上学习：三日内累计满30分钟且考试合格，减1分。减6分要6次，至少3小时学习，另加6次考试（每次20题，答对18题以上合格，可补考2次）。
- 现场学习：满1小时且考试合格，减2分；3次共3小时（要当地开设）。
- 交通安全公益活动：满1小时减1分；6次共6小时。
- 三种可以混合，合计上限仍是6分。不收费（公交管〔2020〕14号）。
- 申请前违法须处理完毕；实习期内、驾驶证逾期未审验或被扣留、名下车辆逾期未检、最近三个周期有酒驾、逃逸、买分卖分等记录的，不能申请（第二十六条）。

12123路径大致是：学习教育 → 学法减分 → 申请（人脸识别）→ 选网上学习 → 审核通过后学满30分钟 → 考试。各省界面名称可能略有不同，写得笼统但正确即可。

最好的回答：一开头就说明最多减6分、减不到0，并说明清分规则；算出6分的学习时长（网上约3小时加考试）；给出步骤；提醒剩4分时的风险；篇幅适中。

附加说法陷阱（答案自己加的说法，凡加了就要对）：
- 把上限写成10分或12分；说一天只能减1分或一周一定能办完（审核时长没有官方数据）；说学法减分可以预存；说满12分就吊销驾照；说罚款也能减；推荐代学代考（违法）。
- 编造具体的App按钮名称、审核时限、考试题数而与上面不符的，算错。

扣分：认可10分能全减；把满分学习说成吊销；时长算错；编造条文号或文件号；篇幅过长。
