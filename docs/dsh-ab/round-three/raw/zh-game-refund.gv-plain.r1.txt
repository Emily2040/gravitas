## 五、以后怎么设置，防止再充

### 1. 微信支付（最关键）

- 关闭免密支付/自动扣款：我 → 服务 → 钱包 → 支付设置 → 免密支付/自动扣款，把游戏相关项全部关掉。
- 开启安全锁：我 → 服务 → 钱包 → 消费者保护/安全保障 → 安全锁，设手势或指纹。
- 关闭指纹/面容支付，改成每次输入密码；支付密码不要和锁屏密码相同，也不要让孩子看到。
- 解绑大额银行卡，只绑一张余额较少、有限额的卡。
- 开启消费提醒，每月查一次账单。
- 微信“青少年模式”可以开，但它不能替代支付锁。

### 2. 手机系统

- iPhone：设置 → 屏幕使用时间 → 内容和隐私访问限制 → iTunes Store 与 App Store 购买项目 → App 内购买 → 不允许；再把“购买与下载”设为“始终需要密码”。
- 安卓：应用商店/Google Play 里开启“购买前询问”；给微信、游戏、应用商店加应用锁；有“儿童空间/青少年模式”就打开。
- 不要让孩子长时间单独拿你的手机玩游戏，玩完退出账号。

### 3. 游戏内

- 设置游戏二级密码、成长守护或家长监护。
- 腾讯游戏可用“腾讯成长守护”，网易游戏可用“网易家长关爱平台”，其他游戏找“游戏名+家长监护平台”。
- 最好给孩子用他自己实名的未成年账号和设备，不要用你的成人账号，这样有时长和充值限额。

### 4. 银行卡

- 给绑定微信的卡设置单笔、单日限额，卡里不要放太多钱。
- 打开短信/微信动账提醒。
- 关闭小额免密支付；不需要的话，关闭无卡支付、境外支付。

### 5. 习惯

- 不把支付密码告诉孩子，输入时注意遮挡。
- 定期看账单，发现异常立刻截图保存。
- 如果退款成功，要求游戏方回收未消耗道具或限制账号，并立刻改支付密码，避免孩子继续充。
