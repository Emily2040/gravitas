**发信前先确认找谁。** 打开微信 → 我 → 服务 → 钱包 → 账单 → 点开那笔充值 → 看“商户全称”。如果收款方是游戏公司，就发给游戏客服；如果是 Apple，就走苹果退款；如果是华为、小米、应用宝这类渠道，就找渠道客服。找错人，这封信会白写。

**关于这封信的几点说明：**

我把诉求写成“先主张全额、同时表示可接受部分退款”。这样比一上来只要一部分留出的谈判空间更大；如果你只想直接要一部分，改第五部分第 1 条即可。

第五条里提到“诉讼”，是给客服一个向上移交的理由，不是真要马上打官司。真走到诉讼，6480 元的案子诉讼费 50 元，可以自己去“人民法院在线服务”立案，但周期长、要请假，值不值得你自己权衡。

只写真实发生的事。时间、金额、次数要和微信账单对得上。编造细节一旦被后台数据戳穿，协商空间就彻底没了。

现在就把证据固定下来：微信账单逐笔截图（含商户全称和订单号）、游戏账号和角色信息截图、和客服的聊天记录、孩子的书面说明。别注销账号，别删游戏，别把充值道具花掉。

**如果被拒，按这个顺序升级：**

1. 微信支付投诉：账单里那笔交易 → 对订单有疑问 → 投诉商户。这会留下支付侧的记录。
2. 12315：电话 12315，或全国12315平台 www.12315.cn，投诉对象写收款方的公司全称（账单里能看到）。
3. 12345 政务服务热线，转属地市场监管。
4. 黑猫投诉等公开平台，主要是施加舆论压力，不产生法律效力。
5. 真起诉，案由是网络服务合同纠纷。

不要找“退款中介”。收手续费、要你提供身份证和支付密码的，基本都是骗局。

**以后怎么防：**

微信这一侧最关键，因为钱是从这里出去的。

- 改支付密码，换成孩子猜不到的，别用生日、手机号后六位。开启指纹或面容支付。
- 我 → 服务 → 钱包 → 支付设置 → 免密支付/自动扣款，逐项关掉。
- 我 → 设置 → 青少年模式，开启并自己保管密码。它会限制小程序、游戏、直播、视频号这些入口；支付部分还要靠上面两步。
- 绑微信的卡只放日常零用钱，大额储蓄卡不要绑。
- 想给孩子零花钱，用“亲属卡”设月度额度，别把主卡交出去。
- 关注“微信支付”公众号，每笔消费都有推送，异常能第一时间发现。

手机系统这一侧，如果是从应用商店下载的游戏，系统层面的开关最硬。

- iPhone：设置 → 屏幕使用时间 → 内容和隐私访问限制 → 打开 → iTunes Store 与 App Store 购买项目 → App 内购买 → 不允许；再把“需要密码”设为始终需要。
- 安卓：应用商店 → 我的 → 支付设置，打开支付密码、关掉免密支付；系统里开“儿童空间”或“学生模式”；给微信加应用锁。

游戏账号这一侧，绑定家长监护后，限额才真正生效。

- 腾讯系：微信搜“成长守护平台”，绑定孩子的游戏账号，设单次和每月消费限额、游玩时段，必要时一键禁玩。
- 网易系：网易家长关爱平台，jiazhang.163.com。
- 其他厂商：游戏内“设置—家长监护/未成年人保护”，或官网客服入口。
- 注意：很多游戏用微信或 QQ 直接登录，绑定了成长守护才管得住。

最后一句，技术手段只能挡住下一次，挡不住他想充的心。找个时间把 6480 元换算成他熟悉的东西讲给他听——多少双球鞋、多少个月的零花钱、你上多少天班。11 岁的孩子听得懂，只是没人跟他算过这笔账。
