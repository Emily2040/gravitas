先说一句实话：客服说“账号实名是你，就按规定算成年人充值”，这是常见的推脱说法，不是法律结论。你可以承认自己监护上有疏忽，但千万别在沟通里把“疏忽”说成“我同意”或“是我充的”；前者最多让退款打折扣，后者会让退款直接归零。这两件事在法律上完全是两回事。

按 11 岁、6480 元、十几次这个情况：全额退有难度，但争取退一部分是有依据的。公开判例里，这类案子判返还的比例大致在五成到全额之间，多数在七成上下；跟平台协商通常比法院判的低一些。所以策略是：**主张全额，接受合理比例，别一上来就松口**。

## 二、发之前，先做四件事

1. **导出账单**：微信 → 我 → 服务 → 钱包 → 账单 → 右上角“常见问题” → “下载账单” → 选“用于证明材料”，选对应月份，填邮箱。每笔点开还有“商户全称”，那就是你后面投诉的对象。
2. **拍户口本或出生医学证明**：证明孩子 11 岁、你是监护人，这是最硬的年龄证据。
3. **让孩子自己写一份说明**（或录一段视频）：什么时候、怎么拿到手机、怎么知道支付密码、充了什么。让他自己写，别代写，真实就行。
4. **截图留证**：游戏角色页、充值记录、和客服的聊天、工单号。**别删游戏、别注销账号、别删聊天记录**，这些是证据。

这封信本身就是“拒绝追认”的书面证据，**一定要发文字，不要只打电话**；打完电话也要求客服在聊天里确认工单号。

## 三、客服常见话术，怎么接

- **“实名是成年人，不退款。”** → “实名只证明注册信息，不证明实际操作人。请转未成年人充值专项，调取登录设备、时段、充值记录。你们不看后台数据就拒绝，我会在 12315 和诉讼中申请调取。”
- **“你怎么证明是孩子充的？”** → “我有初步证据：充值时段、孩子陈述、设备使用情况、游戏内行为。后台数据在你们手里，举证不能只压在家长身上。”
- **“只能退 30% 或 50%。”** → “请说明计算依据和比例构成。我可以协商，但要看到正式方案，不会在电话里口头答应。”
- **“退款要封号、收回道具。”** → “可以接受，请书面写明退款金额、到账时间、账号处理方式。”
- **“时间太久，超过期限。”** → “法律上没有这种退款期限，诉讼时效是三年。请按流程受理。”

## 四、以后怎么防（四道闸门）

### 第一道：支付账户

**微信**
- 关闭免密支付和自动扣款：我 → 服务 → 钱包 → 支付设置 → 免密支付/自动扣款，逐项解约（游戏、App Store、视频会员最容易漏）。
- 关闭生物支付，或只录你自己的指纹：同上 → 生物支付。
- 钱包安全锁：我 → 服务 → 钱包 → 消费者保护 → 安全保障 → 安全锁，设手势或指纹。
- 金额隐私保护：同页开启，别让孩子看到余额。
- 解绑大额银行卡：钱包 → 银行卡，只留一张小额卡，工资卡别绑。
- 用“亲属卡”代替给密码：钱包 → 亲属卡，给孩子开一张，设每月一两百的额度，你随时可停。
- 青少年模式：我 → 设置 → 青少年模式，设独立密码（别用锁屏密码）。
- 登录设备管理：我 → 设置 → 账号与安全 → 登录设备管理，删掉孩子用的设备。

**支付宝**：我的 → 设置 → 支付设置 → 免密支付/自动扣款；安全中心 → 安全锁；亲情卡定额度。

**银行卡**：手机银行 → 限额管理，设单笔和日累计（比如单笔 200、日 500）；关闭小额免密；开通每笔短信提醒。

注意：微信本身没有“单笔限额”开关，限额主要靠银行卡侧和零钱余额控制，所以别在微信里放太多零钱。

### 第二道：手机或平板

- **iPhone/iPad**：设置 → 屏幕使用时间 → 内容和隐私访问限制 → iTunes Store 与 App Store 购买项目 → App 内购买 → 不允许；密码设置 → 始终需要；打开“购买前询问”。屏幕使用时间密码单独设，别让孩子知道。
- **安卓**：应用商店 → 设置 → 支付，关闭免密和小额免密；华为“健康使用手机 → 儿童模式”、小米“儿童空间”、OPPO 和 vivo 的儿童模式，把孩子用的设备设为儿童模式。
- **通用**：锁屏密码、支付密码、屏幕使用时间密码，三个都不一样；输入时遮挡；别用生日、手机号。

### 第三道：游戏平台

- **腾讯系**：微信搜“成长守护平台”小程序 → 绑定孩子账号 → 开“消费管理”和“一键禁玩”，能看消费、限时段。
- **网易**：“网易家长关爱平台”；**米哈游**：“米哈游成长关爱平台”；其他游戏在官网或客服问“家长监护”。
- **改实名**：问客服能不能把账号实名改成孩子本人。能改的话，系统会按未成年人限额（8—16 岁单次 50 元、每月 200 元），这是最硬的一道锁；不能改，就靠成长守护绑定。
- **别帮孩子过人脸识别**。你帮他过一次，退款时平台就会说你“帮助绕过防沉迷”，返还比例直接砍。

### 第四道：习惯

- 每周固定一天花两分钟看微信、支付宝账单；开启每笔消费提醒；每月对一次账。
- 不把绑定大额卡的手机长期给孩子；孩子要用，给访客模式或儿童模式。
- 跟孩子把规则讲清楚：游戏时间、零花钱额度、超支后果；让他知道 6480 元相当于家里多久的什么开支。
- 发现异常，第一时间截图、改密码、找客服，别先删游戏和聊天记录。

## 五、如果还是不退

1. **12315**（小程序、网站或 12315 电话），投诉对象填微信账单里显示的“商户全称”，不是客服。
2. **12345** 市民热线。
3. **国家新闻出版署防沉迷举报平台**（[jubao.chinaso.com](https://jubao.chinaso.com/reportingguide.html)），举报未落实实名、限额、时段。
4. **黑猫投诉**，公开投诉有时比客服管用。
5. 最后才是**诉讼**：6480 元可走小额诉讼，诉讼费几十块，但耗时间，先算值不值。

**三个不要**：不要找收费“退款中介”（多是骗手续费、套账号验证码）；不要在沟通里说“是我充的”“我同意”“密码是我告诉他的”；不要伪造证据，孩子陈述让他自己写。
