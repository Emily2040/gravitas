## 先说判断

这封信值得发，但按全额退款来期望并不现实。你上次被拒，是因为只说了“是我儿子充的”，而对方一句话就能堵回来：“实名是成年人。”这次要把重点从**账号是谁的**转到**操作是谁做的**，并主动把诉求降到“按比例退一部分”。这个数正好落在行业退费标准里，客服有权限批，也更容易往上递。

先纠正一点：你说“我也认了”，认监护疏忽没问题，但那不等于充值有效。法律上看的是三件事：孩子实际实施、金额与年龄不相称、监护人未追认。监护疏忽只影响**退多少**，不影响**能不能退**。最高法2026年3月发布的《人民法院审理涉未成年人民事案件工作指引》第27条讲的就是这个：认定无效后，网络经营者应当返还；各方有过错的，按过错分担。所以你“认错”和“要钱”并不矛盾。

## 发之前，先做两件事

**一、先确认入口对不对。** 普通客服没有退款权限，走普通对话必然收到模板回复。如果是腾讯系的游戏：微信搜“腾讯客服”公众号，发“未成年消费”，按回复填表、上传户口页，等电话回访。不是腾讯的，直接要求“转未成年人退款专员或家长监护专线”，别在普通客服里绕。

**二、把证据固定下来，再发。** 现在就存：微信支付账单里这十几笔的截图（带时间）、孩子出生证明或户口页、孩子自己讲充值过程的视频（让他说角色名、区服、买的是什么）、手机“屏幕使用时间”或应用使用时长的截图、你本人那几天不在场的证明（考勤、监控、出差记录）。**证据必须真实**，编造会被后台数据戳穿，还会被拉黑。

## 如果又是模板回复

别重复讲道理，改成追问，逼对方留下书面记录：

> 请把我的申诉转交未成年人退款专员，并书面回复三个问题：一、你们是否核验过该账号在充值期间的登录设备和实际使用人？二、认定“成年人充值”的依据是实名信息本身，还是另有核验？三、拒绝退款的书面理由和依据条款是什么？

这三个问题对方很难用模板糊过去，也是后面投诉时要用的材料。

## 以后怎么设置

真正的问题不是“游戏账号算谁的”，而是**付款这一关没拦住**。所以重点在微信支付和手机，不在防沉迷。

**第一层：把付款堵死（最有效）**

1. **关免密支付和自动扣款**：微信 → 我 → 服务 → 钱包 → 支付设置 → 免密支付／自动扣款（有的版本叫“扣费服务”），把里面项目逐个关闭。
2. **给钱包上锁**：微信 → 我 → 服务 → 钱包 → 消费者保护 → 安全保障 → 安全锁，开启手势或指纹。同时把“指纹支付”“面容支付”关掉，付款必须输密码。
3. **换支付密码**：不要用锁屏密码，不要用生日，输入时避开孩子。
4. **解绑大额银行卡**：微信 → 我 → 服务 → 钱包 → 银行卡，只留一张余额几百元的卡。再进银行App，给这张卡设单笔和单日限额（比如单笔200、单日500）。这一步是真正的底层保险，游戏和微信都绕不过去。
5. **零钱不留大额**，随用随充。

**第二层：手机**

6. **iPhone**：设置 → 屏幕使用时间 → 内容和隐私访问限制 → 打开，把“购买项目”设为“不允许”，再设一个独立的屏幕使用时间密码。**但注意**：这只拦 Apple 内购，国内手游大多走微信直付，拦不住，所以第1—4条才是主力。
7. **安卓**：用系统自带的应用锁或儿童模式，锁住微信和游戏。
8. **临时方案**：孩子要玩时用“引导式访问”（iPhone 连按三下侧边键）把屏幕锁在游戏里，他退不出去付款；安卓多数品牌也有“固定屏幕”。
9. **长期方案**：给孩子单独一台设备、单独一个微信号，不绑银行卡，用你的“亲属卡”给额度（微信 → 我 → 服务 → 钱包 → 亲属卡），每月上限你定，每笔消费你都能收到通知。

**第三层：游戏侧**

10. **腾讯游戏**：微信搜“腾讯成长守护”小程序，建家庭、绑孩子身份证，能设消费限额、时段、一键禁玩。热线 0755-86013799。
11. **网易**：“网易家长关爱平台”；**米哈游**：“米哈游成长守护”。其他厂商在游戏内“设置—家长监护”里找，或直接问客服要入口。
12. **微信青少年模式**：我 → 设置 → 青少年模式，设独立密码，能挡掉微信里的小游戏和部分入口。

**第四层：让自己第一时间知道**

13. 打开微信支付的每笔交易提醒，银行卡开短信提醒。6480元是十几次刷出去的，只要有提醒，第一次就能拦住。

最后一句：11岁的孩子已经会记密码、会趁人不在操作，纯靠技术拦不住太久。把支付密码和手机管住是底线，剩下的跟他把规则讲清楚——这笔钱最后谁承担、以后怎么算，比装十个软件都管用。
